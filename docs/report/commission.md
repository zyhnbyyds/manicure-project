# 提成（规则 / 计提 / 结算 / 冲销）

> 💡 提成是「做完一单，系统自动给美甲师记一笔钱」。记多少由「提成规则」决定，什么时候发钱由「提成结算」决定。

## 这个模块解决什么问题

- 让提成**算得出来、查得到、说得清**：每一笔提成都记得住是哪张单、哪个项目、按哪条规则、基数多少。
- 避免「凭印象发工资」：规则里没配的项目，系统**不会猜**一个默认比例，直接不提成。
- 已经结算的钱不允许乱改：结算后只能通过冲销处理，保证历史工资单可追溯。

## 谁来用（适用角色）

| 功能                           | 需要什么权限                                  | 建议给谁                         |
| ------------------------------ | --------------------------------------------- | -------------------------------- |
| 看提成规则、新增/编辑/删除规则 | `biz:commission:rule`（页面上叫「提成规则」） | 老板 / 店长                      |
| 看提成记录（提成结算页）       | `biz:commission:list`                         | 店长 / 财务                      |
| 结算本期、单笔冲销             | `biz:commission:settle`                       | **只给店长**（等于发工资的动作） |

> ⚠️ 「提成结算」页面上的「结算本期」和「单笔冲销」两个按钮共用同一个权限点。给谁这个权限，就等于让谁能发钱。

## 操作路径

- 维护规则：后台管理端 → 左侧菜单「美甲预约」→「提成规则」，或 `/biz/commission-rules`
- 结算与查记录：后台管理端 → 左侧菜单「美甲预约」→「提成结算」，或 `/biz/commission-records`

## 分步操作

### A. 配一条提成规则

1. 进「提成规则」，点右上角「新增规则」。
2. 填「规则名称」，例如「美甲项目 10%」。这个名字会出现在每一条提成记录的「命中规则」列里，起个好认的名字。
3. 选「维度」（决定这条规则管哪些单）：
   - **按服务项目**：只针对某一个具体项目（最细）。
   - **按项目分类**：针对一整类项目，例如「延长甲」。
   - **按美甲师**：针对某一位美甲师（必须选人）。
4. 按维度填对应的取值（服务项目 / 项目分类 / 美甲师）。不填会提示不能为空。
5. 填提成比例「比例(‰)」和/或「固定额(元)」：
   - 比例是**千分比**：填 `100` = 10%，填 `150` = 15%，填 `1000` = 100%。
   - 两项可以同时填，实际提成 = 基数 × 比例 + 固定额。
   - 两项都填 0 会被拒绝（提示「比例与固定额至少填写一项」）。
6. 选「计提基数」：默认**实收**，建议保持不变（原因见注意事项）。
7. 填「生效开始」（必填）；「生效结束」留空表示长期有效。
8. 需要时改「优先级」：数字越小越优先，同一维度里只会命中排最前的一条。
9. 「状态」保持开启，点「保存」。
10. 保存后提示「创建成功」。**修改**已有规则时会提示「更新成功（只影响之后计提）」——历史提成不会被重算。

### B. 看某个月一共该发多少

1. 进「提成结算」。
2. 在上方「期间汇总」里选期间（下拉是最近 24 个月，格式 `YYYY年MM月`）。
3. 看四个数字：
   - **本期计提中**：还没结算的钱（这是待发总额）。
   - **本期已结算**：已经结算过的钱。
   - **涉及美甲师**：计提中记录涉及多少人（只统计计提中的记录）。
   - **当前结算期间**：确认你选的月份对不对。
4. 下方的记录表可以按美甲师 / 期间 / 状态筛选，逐笔核对。
5. 想知道某个美甲师这个月拿了多少：筛选「全部美甲师」选人 → 看「计提金额」列合计。

### C. 结算本期（发钱前的最后一步）

1. 在「期间汇总」选好要结算的期间。
2. 点右上角「结算本期」。
3. 系统会弹出二次确认，写明：**本期计提总额、涉及美甲师人数、共多少笔**，并提醒「结算后不可修改，只能冲销」。
4. 如果本期一笔计提中记录都没有，会提示「YYYYMM 没有待结算的计提记录」，不会产生空批次。
5. 点「确认结算」。
6. 成功后提示「结算完成：批次 S202609001，共 X 笔，合计 ¥XXX.XX」。
   - 批次号形如 `S` + 年月 + 三位序号：同期第二次结算就是 `S202609002`。
7. 记录表里的这些记录状态变成「已结算」，并带上结算批次和结算时间。

### D. 冲销一笔提成（算错了 / 单子取消了）

1. 在记录表里找到那一笔，点最右侧的「单笔冲销」按钮。
2. 弹窗里会显示记录号、金额，以及该记录当前状态。
3. **必须填写冲销原因**，不填会提示「请填写冲销原因」。
4. 点「确认冲销」，二次确认里明确写着「记录不会被删除，状态置为『已冲销』」。
5. 成功后那一笔显示为**已冲销**（灰色带删除线）。
6. 如果这笔已经是「已结算」状态，冲销会被拒绝并提示「只有 accrued（计提中）可冲销（结算后不可修改）」。

## 字段说明

### 提成规则表单

| 字段       | 必填                  | 说明                                             | 填错会怎样                                                             |
| ---------- | --------------------- | ------------------------------------------------ | ---------------------------------------------------------------------- |
| 规则名称   | 是                    | 给这条规则起名，会显示在提成记录的「命中规则」列 | 名字太像会分不清是哪条规则在生效                                       |
| 维度       | 是                    | 按美甲师 / 按项目分类 / 按服务项目               | 选错维度 → 规则命中不到，或命中了不该命中的单                          |
| 美甲师     | 维度=按美甲师时必填   | 只对这位美甲师生效                               | 不填会提示「请选择美甲师」                                             |
| 项目分类   | 维度=按项目分类时必填 | 分类取自服务项目的分类字段                       | 不填会提示「请选择项目分类」                                           |
| 服务项目   | 维度=按服务项目时必填 | 只对这一个项目生效                               | 不填会提示「请选择服务项目」                                           |
| 比例(‰)    | 与固定额至少填一项    | 千分比，`50` = 5%，`100` = 10%，上限 1000        | 超过 1000 会被拒绝；填成百分数（例如想设 10% 却填 10）会变成 1%        |
| 固定额(元) | 与比例至少填一项      | 每个项目固定提成多少元                           | 填负数被拒；填成「分」的数值会放大 100 倍                              |
| 计提基数   | 是                    | 实收（默认）/ 应付 / 原价                        | 改成「原价」→ 打折、退款时提成会多发；改成「应付」→ 挂账单也会提前计提 |
| 生效开始   | 是                    | 规则从哪天开始算                                 | 填成未来日期 → 今天的单不提成                                          |
| 生效结束   | 否                    | 留空 = 长期有效                                  | 填早于开始日会被拒绝；填成过去日期 → 规则立即失效                      |
| 状态       | 是                    | 启用 / 禁用                                      | 禁用后新单不提成，历史记录不受影响                                     |
| 优先级     | 否                    | 同维度取数字最小且生效期命中的一条               | 想两条规则叠加提成是做不到的，只会命中一条                             |
| 备注       | 否                    | 给自己的说明                                     | —                                                                      |

### 提成记录列表

| 列名     | 含义                                                |
| -------- | --------------------------------------------------- |
| ID       | 记录编号                                            |
| 关联预约 | 这笔提成来自哪张预约单（显示预约 ID）               |
| 美甲师   | 提成归谁                                            |
| 命中规则 | 命中的提成规则名称；没命中会显示「未配置规则」      |
| 计提基数 | 用来乘比例的那个金额（按规则设定的基数取值）        |
| 计提金额 | 这笔提成多少钱；负数用红色显示并带负号              |
| 期间     | 计提发生的月份（`YYYYMM`），**不是**服务发生的月份  |
| 状态     | 计提中 / 已结算 / 已冲销                            |
| 结算批次 | 已结算的批次号（形如 `S202609001`），未结算显示 `-` |
| 结算时间 | 结算动作发生的时间                                  |

### 提成计算公式

**单笔提成 = 计提基数 × 比例(‰) ÷ 1000 + 固定额**，结果向下取整到分。

**计提基数怎么取**（对应规则里的「计提基数」）：

- **实收**（默认）：这张单实际收到的钱，按项目原价占比分摊到这个项目上。
- **应付**：这张单合同上该收的钱，同样按原价占比分摊。
- **原价**：这个项目的原价，不折扣、不减退款。

**数字例子**

- 场景：某单含两个项目，猫眼美甲原价 ¥168.00、纯色美甲原价 ¥88.00，合计原价 ¥256.00；顾客实付 ¥230.00（打了折）。
- 规则：分类「款式设计」比例 100‰（10%）、基数=实收。
- 猫眼美甲分摊实收 = 230.00 × 168.00 ÷ 256.00 = 150.9375 → 向下取整 **¥150.93**；提成 = 150.93 × 10% = 15.093 → 向下取整 **¥15.09**。
- 纯色美甲分摊实收 = 230.00 × 88.00 ÷ 256.00 = 79.0625 → **¥79.06**；提成 = **¥7.90**。
- 这单合计计提 ¥22.99（两条记录，一个项目一条）。

## 使用注意事项

> ⚠️ **「计提基数」默认必须是实收，别随手改成原价或应付。**
> 触发条件：为了「让美甲师多拿点」把基数改成原价。
> 后果：顾客打折、退单时，提成仍按原价发，等于店里倒贴；挂账单在钱没收到时就先计提了。
> 正确做法：保持默认「实收（默认，防挂账提前计提）」。想多给，就提高比例。

> ⚠️ **没命中规则 = 不提成，系统不会猜默认比例。**
> 触发条件：新项目上线没配规则；新美甲师没配「按美甲师」的规则。
> 后果：员工做完单却没有提成记录，月底对账时才发现，很难补。
> 正确做法：上新项目、招新美甲师时，第一件事是检查「提成规则」是否覆盖；每月结算前先筛一遍「未配置规则」的记录。

> ⚠️ **尾款收清后系统不会自动补提差额。**
> 触发条件：顾客只付了定金就完成服务，尾款过几天才结清。
> 后果：提成按完成那一刻的实收计提，比最终实收少，且**不会自动补**。
> 正确做法：尽量避免先完成再收尾款；确实发生了，就在结算前由店长人工补一笔（或按门店约定在工资里补），并把处理方式写进提成规则备注。

> ⚠️ **改提成规则不会回算历史提成。**
> 触发条件：10 月把比例从 10% 调到 8%，想重算 9 月的提成。
> 后果：历史记录保持原样（每条记录都存了当时命中的规则和基数），不会自动变。
> 正确做法：只需影响今后就什么都不用做；确实要改历史，只能在「提成结算」里逐笔冲销后按新规则人工处理。

> ⚠️ **结算之后不能改，只能冲销，而且「已结算」的记录当前无法冲销。**
> 触发条件：结算后才发现某笔提成算错。
> 后果：系统会提示「只有 accrued（计提中）可冲销（结算后不可修改）」，这笔钱改不动。页面文案里写的「已结算期间的冲销进下一期为负数」在当前版本尚未实现。
> 正确做法：**结算前**把记录逐笔核对清楚（重点看「未配置规则」「关联预约已取消」「金额异常」三类）；确实结算错了，只能在下个月的提成里人工做加减，并在备注里写明。

> ⚠️ **一条规则只会命中一条，提成不能叠加。**
> 触发条件：同时配了「按服务项目 15%」和「按项目分类 10%」，想拿 25%。
> 后果：只有优先级最高的那一条生效（服务项目 > 项目分类 > 美甲师）。想叠加只能把两部分加总写进同一条规则（比例 + 固定额）。
> 正确做法：一条规则里同时填比例和固定额。

> ⚠️ **本期的「总计金额」可能只是个下限。**
> 触发条件：某个月计提记录超过 200 条。
> 后果：页面「本期已结算」等汇总取的是前 200 条合计，卡片上会提示「注意：记录超过 200 条，金额为下界」。
> 正确做法：看到这个提示，就用筛选条件分美甲师/分批核对，不要直接把卡片数字当发钱依据。

> ⚠️ **系统不会自动结算。**
> 触发条件：以为到了「提成结算日」参数（默认每月 5 日）系统会自动关账。
> 后果：不点「结算本期」，提成就永远停在「计提中」，无法锁定。
> 正确做法：每月固定一天由店长手工点「结算本期」。

## 常见问题

**Q：提成是什么时候产生的？**
A：预约状态变成「已完成」的那一刻。一单里有几个项目，就产生几条记录（一个项目一条），因为规则可以按项目/分类区分。

**Q：为什么同一张单里有好几条提成记录？**
A：因为提成是**逐个项目**计提的。一单做了猫眼 + 纯色，就会有两条记录，可能命中不同规则。

**Q：「期间」为什么不等于顾客到店的那个月？**
A：「期间」取的是**计提发生时的月份**。9 月 30 日晚上完成、10 月 1 日才标记完成的单，会算进 10 月。

**Q：顾客取消 / 退款 / 爽约了，提成怎么办？**
A：系统会把对应的计提记录置为「已冲销」（不删除，留痕），前提是它还没被结算。

**Q：怎么查某位美甲师这个月一共该拿多少？**
A：进「提成结算」，期间选当月，美甲师筛那位，状态选「计提中」，把「计提金额」列加起来；或者看期间汇总卡片里的总额（注意 200 条上限提示）。

**Q：比例填 ‰ 是什么意思？我想设 10%。**
A：填 `100`。公式是「基数 × 千分比 ÷ 1000」，100 ÷ 1000 = 10%。

**Q：一条规则能同时管「所有美甲师」吗？**
A：可以，但要用**按项目分类**或**按服务项目**的维度来做。选「按美甲师」维度时**必须指定具体某一位美甲师**，不能留空当「所有人」。

**Q：规则删除了，历史提成还在吗？**
A：在。删除是软删（不再参与今后的计提），历史记录仍保留它当时命中的规则编号，可以追溯。

**Q：冲销原因写给谁看？**
A：给以后查账的人看。原因会存进这条记录的备注里（超长会截断）。写清「单号 + 原因」，例如「9/12 张三退款，全单冲销」。

**Q：结算批次号有什么用？**
A：它是这一次发钱的凭证号（形如 `S202609001`），同一个月多次结算会依次编号，方便和工资表一一对应。

**Q：为什么有的记录金额是负数？**
A：冲销后理论上不会再显示负额（记录直接标记为已冲销）；列表对负数会用红色显示，方便你第一时间发现异常数据。
