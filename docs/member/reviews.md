# 评价

## 这个模块解决什么问题

顾客做完项目后可以给美甲师打分、写几句话。店长需要：

- **看到**顾客的真实反馈（尤其是不满意的地方）；
- **回复**顾客（让好评的人看到门店的回应，也让差评有个解释的机会）；
- **隐藏**恶意或不适内容（不要让它展示给其他顾客）；
- **代录**——很多顾客不会用小程序，但会当面口头评价。

页面副标题一句话概括了核心规则：**「一单一评；可回复、可隐藏（处理恶意评价）、可代录」**。

> 💡 **「一单一评」是什么意思**：一次服务（一张已完成的预约）**只能有一条评价**。同一张单不能评两次——不管是从小程序评的，还是店员代录的。这条规则是系统硬拦的。

## 谁来用（适用角色）

| 角色 | 能做什么 | 权限点 |
| --- | --- | --- |
| 店长 | 查看全部评价、回复、隐藏 / 公开、删除、代录 | 评价管理-新增 / 回复 / 隐藏 / 删除 |
| 美甲师 | **只能看到自己的评价**（本人被隐藏的评价也看不到） | — |
| 顾客（小程序） | 对**自己已完成**的预约提交一次评价 | — |

> 💡 美甲师看到的范围是系统自动限定的：只有具备「管理全部预约」权限的账号（一般是店长 / 超管）才能看到所有人的评价。这是为了保护顾客与美甲师双方的隐私。

## 操作路径

后台管理端 → 左侧菜单「美甲预约」→「评价管理」，或直接访问 `/biz/reviews`

## 分步操作

### 一、看评价列表

页面顶部有五个筛选条件：

| 筛选项 | 选项 |
| --- | --- |
| 美甲师 | 全部美甲师 / 具体某位 |
| 评分 | 全部评分 / 5 分 / 4 分 / 3 分 / 2 分 / 1 分 |
| 状态 | 全部状态 / **已发布** / **已隐藏** |
| 评价日期 | 从 … 至 … |

列表每一行：

| 列名 | 说明 |
| --- | --- |
| ID | 评价编号 |
| 预约单号 | 这条评价是哪次服务留下的 |
| 顾客 / 美甲师 | 谁评的、评的谁 |
| 评分 | 用 ★ 星显示，鼠标悬停能看到「X 分」 |
| 评价内容 | 顾客写的文字 |
| **公开** | 「公开」/「不公开」——控制这条评价是否展示给其他顾客 |
| 店家回复 | 门店的回复内容；没回复时显示「**未回复**」 |
| 状态 | 「已发布」/「已隐藏」 |
| 评价时间 | 提交时间 |

> 💡 **「公开」和「状态」是两件事**：「公开」是这条评价的可见性开关；「状态」是「已发布 / 已隐藏」。隐藏的评价，顾客侧不再展示。

### 二、回复评价

1. 在某一行的「操作」里点「**回复**」。
2. 弹窗标题「回复评价」，上半部分会展示顾客的原话与评分：
   - 「顾客评价：」后面是原文（顾客没写内容时显示「（未填写内容）」）；
   - 「评分：」后面是 ★ 星级。
3. 在输入框里写回复，占位提示是「请输入店家回复（**公开可见**）」——注意回复是给顾客和其他人看的，别写内部信息。
4. 点「提交回复」→ 提示「回复成功」。
5. 回复后列表的「店家回复」列会显示内容，不再显示「未回复」。回复内容长度限制 1~500 字；空着提交会提示「请填写回复内容」。

### 三、隐藏 / 公开评价（处理恶意评价）

1. 点「**隐藏**」图标（已经是隐藏状态的会变成「公开」）。
2. 确认窗：
   - 隐藏：「确定隐藏该评价吗？**隐藏后顾客侧不再展示**。」；
   - 公开：「确定公开该评价吗？**公开后将展示给顾客**。」
3. 确认后提示「已隐藏」或「已公开」。

隐藏的效果：

- 顾客侧不再展示这条评价；
- **该美甲师本人也看不到**（系统把隐藏理解为「按下不表」）；
- 计算平均分时**不计入**隐藏的评价。

> ⚠️ 隐藏是给「恶意评价、辱骂、泄露隐私、明显与事实不符」准备的，不是给「差评」准备的。把正常的差评藏起来会掩盖真实问题，也会让美甲师失去改进的线索。**建议先在回复里认真解释，再决定要不要隐藏。**

### 四、删除评价

1. 点「删除」图标；
2. 确认窗「确定删除该评价吗？**软删保留数据，列表不再展示**。」；
3. 确认后提示「删除成功」。

删除是**软删除**：数据仍在库里（便于争议时追溯），只是列表里不再展示。

### 五、代录评价（顾客当面口述）

1. 点右上角「**代录评价**」；
2. 填：

| 表单字段 | 怎么填 | 提示 |
| --- | --- | --- |
| 已完成预约 | 必填。下拉里列出可评价的已完成预约，格式如「B20260101001 · 张女士 · 01-01 10:00」 | 「**一单一评，已被评价过的预约提交会被拒绝**」「请选择预约」 |
| 评分 | 必填，默认 **5 分**，可选 1~5 分 | 「不能为空」 |
| 评价内容 | 把顾客说的写下来，占位提示「顾客当面口述的内容」 | — |

3. 点「保存」→ 提示「代录成功」。

> ⚠️ **代录同样受「一单一评」约束。** 如果这张预约顾客已经在小程序里评过了，提交会被拒绝（「该预约已评价（一单一评）」）。**不要为了多刷一条好评而给同一张单代录两次**——系统不允许。

> ⚠️ **代录要写顾客真实说的话。** 评价会展示给其他顾客，也是美甲师提成之外的重要反馈。代录时请如实记录，尤其是不满意的部分。

### 六、顾客侧（小程序里）是什么样

顾客在小程序「服务评价」页看到的是：

- 「这次做的满意吗？」+ 1~5 星评分，星级旁有文字：`非常满意` / `还不错` / `一般` / `不太满意`；
- 「给美甲师点个赞」+ 快捷标签：`手艺细腻` / `沟通耐心` / `环境干净` / `款式还原度高`（选中的标签会拼进评价内容里）；
- 「想说点什么」+ 最多 500 字的输入框（有字数计数）；
- 图片区：提示「**最多可上传 9 张，图片功能开发中**」，点了会提示「图片上传开发中，先写点文字吧」——**当前版本不支持上传图片**；
- 「提交评价」按钮。

提交成功后顾客看到「评价成功 / 谢谢你的反馈，我们会继续加油～」。

**顾客能评价的条件**（系统强制校验）：

| 条件 | 不满足时的提示 |
| --- | --- |
| 必须是**本人**的预约 | 「只能评价自己的预约」 |
| 预约必须是**已完成**状态 | 「只能对状态为 completed 的预约评价」（顾客侧会看到「没找到这笔订单」之类的提示） |
| 这张预约**没被评过** | 「该预约已评价（一单一评）」 |

## 字段说明

| 字段 | 必填 | 说明 | 填错会怎样 |
| --- | --- | --- | --- |
| 已完成预约（代录） | 是 | 只能从「已完成」的预约里选 | 不选 → 「请选择预约」；选了已被评价的 → 「该预约已评价（一单一评）」 |
| 评分 | 是 | 1~5 分，默认 5 分 | 超出范围会被拒绝；代录时**默认就是 5 分**，代录差评要手动改小 |
| 评价内容 | 否 | 顾客的原话，最多 1000 字（小程序端输入上限 500 字） | 不填也能提交（列表里内容为空） |
| 店家回复 | 回复时必填 | 公开可见，最长 500 字 | 空 → 「请填写回复内容」 |
| 状态（已发布 / 已隐藏） | 是 | 隐藏后顾客侧不展示，平均分也不计 | 隐藏正常差评会掩盖问题 |
| 公开（是/否） | 是 | 是否对外展示 | 关掉后顾客看不到这条评价 |

## 使用注意事项

> ⚠️ **一单一评是硬规则，删了也不行。** 系统在判断「这张单有没有被评过」时**不看有没有被软删**——也就是说，即使你把一条评价删掉了，那张预约**仍然是「已评价」**，不能重新提交。所以**不要用「删掉再重录」的方式来修改评价内容**；要改内容，请在回复里补充说明。

> ⚠️ **只有「已完成」的预约能评价。** 「已到店」还没点完成、或者已取消、爽约的预约，都不能评价。如果顾客说评不了，先到「预约管理」看这张单的状态是不是「已完成」。

> ⚠️ **隐藏会影响平均分。** 计算美甲师平均分时只统计「已发布」的评价，被隐藏的不计入。所以隐藏评价会同时改变平均分——请把它当成绩效数据的一部分来慎重使用。

> ⚠️ **回复是公开可见的。** 输入框里明确写着「请输入店家回复（公开可见）」。**不要在回复里写顾客的手机号、消费金额、内部备注、员工姓名等隐私信息。**

> ⚠️ **美甲师看不到被隐藏的评价，也看不到别人的评价。** 美甲师账号登录后台只能看到自己的评价；如果你希望他了解某条被隐藏的差评，需要当面沟通。

> ⚠️ **顾客侧目前不能上传图片。** 页面上写着「最多可上传 9 张，图片功能开发中」，点了只会有提示。跟顾客沟通时不要说「可以传图」。

> ⚠️ **不是每张单都会收到评价。** 系统会在服务完成时给顾客发一条「完成致谢与评价邀请」通知（短信通道未配置时只发站内消息），但顾客评不评是自由的。门店可以用「代录」帮不会用小程序的顾客留下反馈。

## 常见问题

**Q：为什么这张预约在「代录评价」的下拉里找不到？**
A：三个可能：① 这张预约还不是「已完成」状态；② 这张预约已经被评过了（包括被删掉的评价，一单一评不会因为删除而释放）；③ 它不属于当前筛选范围。

**Q：顾客评错了，我能帮他改吗？**
A：系统不提供「修改评价内容」的功能，只能：① 用「店家回复」补充说明；② 用「隐藏」把它从顾客侧撤下。**不要删了再让顾客重评**——那张单已经占用「一单一评」名额，重评会被拒绝。

**Q：我把评价删了，那张预约能重新评价吗？**
A：不能。删除是软删，系统仍然认为这张预约「已评价」。

**Q：恶意差评怎么处理？**
A：先用「隐藏」把它从顾客侧撤下（确认窗会告诉你「隐藏后顾客侧不再展示」），再按门店规定处理（联系顾客、内部沟通）。**隐藏不会被顾客看到「你隐藏了我的评价」**，他只会看不到。

**Q：美甲师自己能看到顾客的差评吗？**
A：能看到「已发布」的评价（含差评）。只有被「隐藏」的评价，本人也看不到。

**Q：评价和提成有关吗？**
A：系统里评价**不直接参与提成计算**（提成按规则与金额算），但评价内容会随「完成致谢与评价邀请」的流程被记录，是管理美甲师服务质量的重要依据。

**Q：为什么列表里「店家回复」一直显示「未回复」？**
A：说明还没回复过。点「回复」写一段话就能提交，回复是公开可见的。

**Q：顾客在小程序里说评不了，提示「只能评价自己的预约」？**
A：说明他当前绑定的手机号对应的顾客档案，和这张预约的顾客不是同一个人。请核对他在小程序里绑定的手机号；如果他换了号，需要在顾客档案里改手机号，并让他重新授权一次。
