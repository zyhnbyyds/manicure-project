# 会员等级与折扣

## 这个模块解决什么问题

门店想让老客越消费越划算：消费到一定金额就自动升级，等级越高折扣越大，而且**不需要人工判断该给几折**——系统按顾客的累计消费自动算。

这一页定两件事：

1. **每个等级打几折**（折扣率）；
2. **消费到多少钱升到这一级**（升级门槛）。

页面副标题就是「等级折扣率与升级门槛」。

> 💡 大白话：等级是「按累计消费自动发的一张身份卡」。顾客自己不用申请，钱花够了系统就自动给他升级；收银时系统也会自动按他的等级打折。

## 谁来用（适用角色）

| 角色        | 能做什么                                                 | 权限点                      |
| ----------- | -------------------------------------------------------- | --------------------------- |
| 老板 / 店长 | 新增、修改、删除等级                                     | 会员等级-新增 / 修改 / 删除 |
| 店长        | 另外还能在「会员管理」里手工调某个顾客的等级（要填原因） | 会员管理-调整               |
| 前台        | 只读：收银时会自动按等级打折，不需要手动选               | —                           |

## 操作路径

后台管理端 → 左侧菜单「美甲预约」→「会员等级」，或直接访问 `/biz/member-levels`

## 分步操作

### 一、看懂「千分比」（最重要的一件事）

这一页的折扣率用的是**千分比**（‰），不是百分比，也不是「几折」。记一个换算法就不会错：

> **千分比 ÷ 10 = 打折的百分数**
> **1000 = 原价 100%（不打折）；950 = 95%（也就是 9.5 折）；880 = 88%（也就是 8.8 折）**

界面上会把千分比直接翻译成「几折」，所以你看到的是：

| 你填的千分比 | 界面显示的折扣 | 顾客实际付 | 原价 100 元应付                                 |
| ------------ | -------------- | ---------- | ----------------------------------------------- |
| 1000         | 打折           | 100%       | 100 元（但注意：表单里**不允许填 1000**，见下） |
| 950          | 9.5 折         | 95%        | 95 元（省 5 元）                                |
| 880          | 8.8 折         | 88%        | 88 元（省 12 元）                               |
| 750          | 7.5 折         | 75%        | 75 元（省 25 元）                               |

**举例（心算）**：原价 200 元，顾客是金卡（950）→ 优惠 = 200 × 5% = **10 元**，应付 **190 元**。
原价 200 元，顾客是钻卡（880）→ 优惠 = 200 × 12% = **24 元**，应付 **176 元**。

> ⚠️ **「不打折」不是靠填 1000 实现的。** 表单里明确不许填 1000：填写时会实时提示「**1000‰ = 不打折，不允许配置**」，保存时会被拦下，提示「折扣率必须大于 0 且小于 1000‰（1000‰ = 不打折，不允许）」。那么「不打折」怎么表达？——**把门槛最低的那一档当作默认等级**（系统预置的「银卡」就是 1000‰，它是系统给的初始档，新建的等级请填 1~999）。

### 二、查看与调整现有等级

打开页面会看到系统预置的三档等级：

| 等级名 | 折扣   | 升级门槛(元) | 排序 | 备注（系统原文）                   |
| ------ | ------ | ------------ | ---- | ---------------------------------- |
| 银卡   | 不打折 | 0.00         | 1    | 默认等级，无折扣（1000‰ = 不打折） |
| 金卡   | 9.5 折 | 500.00       | 2    | 累计消费满 ¥500 升级，95 折        |
| 钻卡   | 8.8 折 | 2000.00      | 3    | 累计消费满 ¥2000 升级，88 折       |

含义：**累计消费满 500 元自动升金卡（9.5 折），满 2000 元自动升钻卡（8.8 折）。**

### 三、新增 / 修改等级

1. 点右上角「**新增等级**」（或某一行上的「编辑」图标）。
2. 填表：

| 表单字段     | 怎么填                                | 系统提示原文                                                        |
| ------------ | ------------------------------------- | ------------------------------------------------------------------- |
| 等级名       | 必填。占位提示「如 黄金会员」         | 不能为空；重名会提示「等级名称已存在」                              |
| 折扣率(‰)    | 必填，填 1~999 的整数千分比，默认 950 | **「千分比：950 = 9.5 折，1000 = 不打折；必须大于 0 且小于 1000」** |
| 升级门槛(元) | 累计消费达到这个金额就自动升上来      | **「累计消费达到该金额后自动升级（只升不降）」**                    |
| 排序         | 由低到高排（1 = 最低档）              | **「由低到高，门槛必须随排序单调不减」**                            |
| 状态         | 启用 / 禁用开关                       | —                                                                   |
| 备注         | 选填                                  | —                                                                   |

3. 填折扣率时会**实时换算**给你看：「当前折扣率换算：≈ 9.5 折」；填了不合理的值会提示「请输入 1~999 之间的千分比，如 950」。
4. 点「保存」。

### 四、删除等级

1. 点某一行上的「删除」图标；
2. 确认窗：「确定删除会员等级「金卡」吗？**有会员在该等级时会被拒绝**。」
3. 如果有会员正处在这个等级上，系统会拒绝并提示「有会员处于该等级，不能删除」——**先把这些会员调到别的等级**（或等他们自动升上去），再删。

> 💡 大白话：等级是「在用的东西」，不能一边有顾客用着一边把它删掉。要下线一个等级，正确做法是把它「禁用」（不再升级上去），而不是直接删。

### 五、自动升级 / 降级规则

**什么时候升级**：顾客的收款成功、累计消费增加时，系统会自动检查一遍：

- 取所有**启用**的等级中，「升级门槛 ≤ 该顾客累计消费」的**最高那一档**作为他的新等级；
- 升级会写一条流水，备注形如「自动升级：银卡 → 金卡」。

**举例**：顾客原来累计消费 480 元（银卡）。这次消费 200 元 → 累计 680 元 → 达到金卡门槛 500 元 → **自动升为金卡**，从下一次算价起享受 9.5 折。

**会不会降级**：**正常情况不会。** 系统是「只升不降」的——消费退款导致累计消费减少时，等级**不会**自动掉下来。只有两种情况会变动等级：

| 什么情况 | 说明                                                                                                                              |
| -------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 系统重算 | 后台「会员管理 → 重算」按钮，或每天凌晨 3:30 自动跑一次的「会员等级重算」任务。它按最新的累计消费重新判定等级，**可能升也可能降** |
| 手工调级 | 店长在「会员管理 → 调级/调积分」里手动改，**必须填原因**，并会写一条「等级变更」流水                                              |

> ⚠️ **重算会覆盖手工调级的结果。** 界面上的提示原文是「手工调级会写 level_change 流水，且会被「重算」覆盖」，重算确认窗也写着「重算会覆盖手工调级结果，确定继续吗？」。所以给某位顾客手工调级只是临时安排；一旦跑了重算，系统会按累计消费把他放回「本该在」的等级。

### 六、等级折扣是怎么算进每一单的

收银台中间栏会把这笔优惠单独列出来，名字就叫「**等级优惠（9.5 折）**」，旁边显示优惠金额（例如 `- ¥10.00`）。

```
项目原价  →  减 等级优惠  →  减 积分抵扣  →  加/减 手动改价  =  应付金额
```

三条必须知道的规则：

1. **折扣看的是「下单那一刻」的等级。** 金额在成交时就固定下来并留档；
2. **事后改等级不影响历史单据**。给顾客升了级，他上周的单子还是按上周的折扣算的，不会追溯重算；
3. **折扣叠加积分抵扣**：先算等级折扣，再算积分抵扣（积分抵扣的上限按**折后金额**算）。

## 字段说明

| 字段         | 必填 | 说明                                   | 填错会怎样                                                                                                                                     |
| ------------ | ---- | -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 等级名       | 是   | 显示在会员列表、会员详情、收银台的位置 | 空 → 「不能为空」；重名 → 「等级名称已存在」                                                                                                   |
| 折扣率(‰)    | 是   | 1~999 的整数千分比；分子越小折扣越低   | 填 0 或 1000 会被拦：「折扣率必须大于 0 且小于 1000‰（1000‰ = 不打折，不允许）」；填非整数会提示「折扣率必须是 0~1000 的整数千分比」           |
| 升级门槛(元) | 是   | 累计消费达到该金额自动升上来           | 负数会被拒（「升级门槛必须是非负整数（分）」）；**门槛高低必须和排序一致**，否则提示「等级门槛必须随排序单调不减：『金卡』排序更小但门槛更高」 |
| 排序         | 是   | 数字越小档位越低                       | 排序和门槛对不上会被拒绝保存；排序错乱会导致「升级取最高档」取错                                                                               |
| 状态         | 是   | 启用 / 禁用                            | 禁用后不再往这一档升级（已有会员保留原等级，不会掉档）                                                                                         |
| 备注         | 否   | 写清这一档的用意，方便以后改           | 只影响可读性                                                                                                                                   |

**关于「门槛必须随排序单调不减」**：意思是排序越大的等级，门槛必须越**高**（或相等），不能出现「排序 2 的门槛比排序 1 还低」这种混乱。举例：

| 排序 | 等级 | 门槛 | 是否允许                                |
| ---- | ---- | ---- | --------------------------------------- |
| 1    | 银卡 | 0    | ✅                                      |
| 2    | 金卡 | 500  | ✅                                      |
| 3    | 钻卡 | 2000 | ✅                                      |
| 1    | 银卡 | 0    | ❌ 排序 2 的门槛 300 比排序 3 的 200 高 |
| 2    | 金卡 | 300  | ❌ 同上                                 |
| 3    | 钻卡 | 200  | ❌ 同上                                 |

## 使用注意事项

> ⚠️ **折扣率是「千分比」，填之前先换算。** 想给 9 折就填 **900**（不是 90、不是 9、不是 0.9）。这是这一页最容易填错的地方。填错一位数字，顾客买单时就会多付或少付一大截。改完建议立刻拿一笔小额单试算核对。

> ⚠️ **1000 只能在系统预置的默认等级上存在，新建等级请填 1~999。** 如果想让某个等级「不打折」，请直接复用现有的「银卡」而不是新建一个 1000‰ 的等级。

> ⚠️ **等级门槛和排序必须一起改，而且要保持单调。** 想把金卡门槛从 500 改成 800、钻卡门槛从 2000 改成 1500，这种改法会被拒绝。请按「门槛随排序递增」的规则设置。

> ⚠️ **不要把「不打折」的默认档删掉。** 系统预置的「银卡」（门槛 0、不打折）是所有新会员的落脚点。删了它，新顾客可能没有等级可用。要下线某个等级，优先用「禁用」而不是「删除」。

> ⚠️ **有会员在用的等级删不掉。** 提示「有会员处于该等级，不能删除」。先想清楚：是这些人真的不该在这个等级，还是你只是不想再让别人升上来？后者用「禁用」。

> ⚠️ **手工调级会被重算覆盖。** 老客户答谢、补偿性的临时升级，请**同时记好原因**（系统会写进流水），并知道它可能被每日 3:30 的等级重算任务改回去。要长期生效，请改等级门槛，而不是给单人调级。

> ⚠️ **改等级不影响历史单据。** 改完折扣率后，之前已经成交的单子还是按旧折扣算的。这是刻意设计，别指望「改了价格系统会重算老单」。受影响的是**之后**的新单。

> ⚠️ **退款不会让顾客自动降级。** 退款会回减累计消费，但等级是「只升不降」的。如果门店希望退款后严格按消费额定级，需要跑一次「重算」（这会同时影响所有会员，请谨慎）。

## 常见问题

**Q：我想给顾客打 8 折，折扣率填多少？**
A：填 **800**。（8 折 = 80% = 800‰）

**Q：为什么表单里不让我填 1000？**
A：因为 1000‰ 就是「不打折」，而系统对「不打折」的表达方式是**门槛最低的那一档**（预置的「银卡」）。表单会实时提示「1000‰ = 不打折，不允许配置」。

**Q：顾客消费了 600 元，为什么还是不打折？**
A：看他的「累计消费」是不是已经达到金卡门槛（默认 500 元）。**升级看的是累计消费，不是单次消费**。如果累计已经超过 500 还是银卡，到「会员管理」点一次「重算」。

**Q：我刚给顾客升了级，他现在来消费怎么还是老折扣？**
A：先确认等级真的改成功了（会员详情里能看到当前等级）。如果等级已改但折扣没变，到「会员管理 → 重算」跑一次重算。

**Q：等级能最多建几个？**
A：系统没有硬性数量限制，但**门槛必须随排序单调不减**，而且档位太多前台和顾客都记不住。一般 3~4 档足够。

**Q：能不能给不同顾客不同折扣（例如熟人价）？**
A：等级折扣是全店统一的。针对单个人的优惠请用**手动改价**（在预约/收银时改价，需要「改价」权限并填原因），或者给他发一张优惠券。不要为了一个人新建一个等级。

**Q：升级通知会发给顾客吗？**
A：系统会在服务完成、充值成功等时点给顾客发通知（模板由店长维护），但**没有专门的「升级通知」模板**。想让顾客知道自己升级了，需要前台口头告知。
