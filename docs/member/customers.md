# 顾客档案

## 这个模块解决什么问题

顾客档案是整个会员体系的**地基**：余额挂在这里、积分挂在这里、次卡挂在这里、消费记录也挂在这里。

页面副标题写得很直白：**「顾客即会员档案；到店统计由「已完成」预约驱动，可手动重算」**。

这个页面解决四件事：

1. **建档**：新顾客第一次来，录一条档案（姓名 + 手机号）；
2. **查档**：按姓名 / 手机号 / 会员号找人，一眼看到余额、积分、消费、到店次数；
3. **保护档案**：有预约记录的顾客**不能被删掉**（删了服务历史就断了）；
4. **删了还能救回来**：误删的档案可以「恢复」，余额积分次卡历史一并回来。

> 💡 大白话：顾客档案不是「通讯录」，是**账本的主人**。删掉一条档案，等于把这个人所有的消费记录、余额、次数都藏起来，所以系统对删除管得很严。

## 谁来用（适用角色）

| 角色          | 能做什么                                    | 权限点                            |
| ------------- | ------------------------------------------- | --------------------------------- |
| 前台 / 收银员 | 建档、查看、编辑、查看历史预约              | 顾客档案-查询 / 新增 / 修改       |
| 店长          | 上面全部 + 删除档案、恢复档案、重算到店统计 | 顾客档案-删除（删除建议只给店长） |

## 操作路径

后台管理端 → 左侧菜单「美甲预约」→「顾客档案」，或直接访问 `/biz/customers`

## 分步操作

### 一、给新顾客建档

1. 点右上角「**新增顾客**」。
2. 填写表单：

| 表单字段 | 填什么                                                                                   | 界面提示                   |
| -------- | ---------------------------------------------------------------------------------------- | -------------------------- |
| 姓名     | **必填**                                                                                 | 占位提示「如 张女士」      |
| 手机号   | 强烈建议填（会员必须有）。提示原文：**「选填（散客可不填）；手机号唯一，重复会被拒绝」** | 占位提示「如 13800000002」 |
| 性别     | 未知 / 女 / 男，默认「未知」                                                             | —                          |
| 生日     | 选填，格式 年-月-日                                                                      | 占位「选填」               |
| 备注     | 选填。建议写偏好，例如「偏好裸色系」「对某品牌胶过敏」                                   | 占位「选填，如偏好裸色系」 |

3. 点「保存」→ 提示「创建成功」。
4. 列表里能立刻看到这条档案，包括手机号、性别、会员号、到店次数、累计消费、积分、储值余额、状态。

> 💡 大白话：**留了手机号就是会员了。** 不用再点任何「入会」按钮。手机号是会员身份的唯一凭据，也是顾客在小程序里找回自己档案的钥匙。

### 二、找人（筛选与查看）

- 搜索框输入**姓名 / 手机号**（支持模糊搜索）；
- 「储值余额」筛选：有储值余额 / 无储值余额（用来快速找出卡里还有钱、需要催消费的顾客）；
- 「**档案状态**」筛选：**在用档案**（默认）/ **已删除档案**（找被删过的人必须切到这个）。

列表每一行的关键列：

| 列名     | 看什么                                         |
| -------- | ---------------------------------------------- |
| 会员号   | 形如 `M20260101001`；空着显示 `-` 表示还没入会 |
| 到店次数 | 完成过多少次服务                               |
| 最近到店 | 最后一次完成服务的时间                         |
| 累计消费 | 一共消费了多少（用来判等级）                   |
| 积分     | 当前可用积分                                   |
| 储值余额 | 本金 + 赠送的合计                              |
| 状态     | 在用 / 已删除                                  |

### 三、看某个顾客的历史预约

点某一行的「**历史预约**」图标，右侧抽屉打开，标题是「历史预约 - 顾客姓名」。

抽屉分两块：

- **档案**：手机号、会员号（没入会显示「未入会」）、到店次数、最近到店、累计消费、积分、储值余额、备注；
- **历史预约**：单号、开始时间、时长（如「75 分钟」）、项目（多个项目用「、」连接）、应付、已收、服务状态、资金状态。

服务状态的中文口径：`待确认`（还没确认）/ `已确认` / `已到店` / `已完成` / `已取消` / `爽约`；
资金状态的中文口径：`未收款` / `部分收款` / `已结清` / `已退款` / `挂账`。

### 四、重算到店统计（数字对不上时用）

「到店次数」和「最近到店」是由**已完成**的预约驱动的。如果发现数字和实际不符（例如以前手工改过状态），可以重算：

1. 点某一行的「**重算到店统计**」图标；
2. 确认窗写明：「将按「已完成」的预约重新计算「某某」的到店次数与最近到店时间（**幂等，可反复执行**）」；
3. 点「重算」→ 提示「重算完成：到店 5 次，最近 2026-01-08 14:30」。

重算是安全的，可以反复点；它只按「已完成」的预约算，不会凭空造数。

### 五、删除顾客（有预约就删不掉）

1. 点某一行的「**删除**」图标。
2. 确认窗写明：「确定删除顾客「张女士」吗？**存在预约记录时会被拒绝**。」
3. 点「删除」：
   - **这个人有预约记录** → 系统拒绝，并明确告诉你：「顾客「张女士」存在 3 条预约记录（B20260101001、B20260102002、B20260103003），不能删除」；
   - **这个人没有任何预约记录** → 删除成功，档案状态变成「已删除」。

> ⚠️ **为什么有预约就删不掉？** 因为预约记录里写着服务历史、金额、退款。如果档案能被删掉，这些历史就变成了「没有主人的记录」，报表、对账、退款追溯全都会断。所以系统的规矩是：**只要服务过一次，这条档案就要留着。**

### 六、恢复被删的顾客

1. 把「档案状态」筛选项切到「**已删除档案**」，找到那条。
2. 点「**恢复档案**」图标。
3. 确认窗写明：「确定恢复顾客「张女士」吗？**恢复后会一并恢复其余额、积分、会员与次卡历史，小程序可重新绑定该手机号**。」
4. 点「恢复」→ 提示「恢复成功」。这条档案重新出现在「在用档案」里。

恢复时如果这个手机号已经被**另一条在用档案**占用了，系统会拒绝，并告诉你：「手机号 138xxxx0002 已被在用顾客「李女士」(#20) 占用，不能恢复；请先改掉其中一方的手机号。」——这是防止两条档案抢同一个手机号。

### 七、顾客在小程序里绑定（顾客↔会员↔微信的关系）

这是顾客档案和微信之间最重要的一段逻辑，请前台和店长都理解：

```
顾客的微信（小程序）
      ↓ 授权手机号
   手机号  ←—— 这是唯一的连接点
      ↓ 系统按手机号查找
   顾客档案（也就是会员档案）
      ↓ 找到 / 新建
   从此小程序里看到：等级折扣、储值余额、积分、次卡、优惠券
```

具体行为：

| 情况                           | 系统的处理                                                                                                                                |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 手机号**已有**档案             | 直接绑定到这条档案，顾客立刻能看到自己的余额 / 积分 / 次卡                                                                                |
| 手机号**没有**档案             | 自动为顾客新建一条档案（姓名取微信昵称，取不到就按手机号后四位生成，例如「微信顾客0002」）                                                |
| 手机号属于一条**已删除**的档案 | **不会自动恢复**，会提示「该手机号的历史档案已被门店删除（顾客 #12 张女士），请联系门店恢复后再绑定」——需要门店在顾客档案里点「恢复档案」 |
| 同一个微信**换绑**到别的手机号 | 新关系会覆盖旧关系（**一个微信同时只绑定一个顾客档案**），并且系统会留下换绑记录以便追溯                                                  |

> ⚠️ **系统不会因为小程序授权就自动恢复被删档案。** 恢复会把余额、积分、次卡历史一起带回来，属于「动账」的动作，必须由门店在后台确认，不能让顾客在小程序里自己决定。

> ⚠️ **小程序没配置微信凭据时，顾客根本进不去。** 后台技术配置里没有填小程序 AppID / 密钥时，小程序登录会返回「**小程序端未启用**」。这时顾客只能到店由前台操作，不要承诺「你在小程序里就能看到」。

## 字段说明

| 字段   | 必填               | 说明                                   | 填错会怎样                                                                                                                                          |
| ------ | ------------------ | -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 姓名   | **是**             | 显示在下拉、列表、收银台里的称呼       | 不能为空                                                                                                                                            |
| 手机号 | 否（但会员必须有） | **全店唯一**，也是小程序绑定的唯一锚点 | 重复会提示「手机号 138xxxx0002 已被顾客「张女士」(#12) 使用」；**如果这个号属于一条已删除档案**，会提示「该手机号属于已删除顾客 #12，请恢复该顾客」 |
| 性别   | 否                 | 未知 / 女 / 男                         | 只影响展示，不影响任何计算                                                                                                                          |
| 生日   | 否                 | 用于顾客关怀（例如生日活动）           | 填错格式保存不上                                                                                                                                    |
| 备注   | 否                 | 偏好、注意事项                         | 不影响系统计算，但**这是美甲师了解顾客的唯一书面途径**，建议填                                                                                      |

## 使用注意事项

> ⚠️ **删掉的手机号仍被占用。** 「删除」是**软删除**（把档案收起来），不是销毁。被删档案的手机号**依然占着这个号**，别人用不了。所以：
>
> - 想给新顾客用这个号 → 必须先**恢复**旧档案，把旧档案的手机号改掉，或者确认旧档案就是他本人；
> - 直接新建会撞上「手机号属于已删除顾客 #12，请恢复该顾客」。
>
> **正确做法**：先确认这个手机号是不是同一个人的。是本人 → 恢复旧档案；不是本人 → 先恢复旧档案、把旧档案的手机号改掉，再给新顾客用。

> ⚠️ **有预约记录的顾客删不掉，这是保护而不是故障。** 看到「存在 N 条预约记录，不能删除」时不要想办法绕过。确实要删除的条件是：这个人**一条预约都没有**（例如建重复了、建错了）。

> ⚠️ **不要为了「重开一条干净的档案」而删除老档案。** 老档案上有余额、积分、次卡、消费历史。删了它，小程序会提示「历史档案已被门店删除」，顾客会以为自己的钱没了。要改资料就直接改。

> ⚠️ **恢复档案前先确认没有手机号冲突。** 恢复不是必成功：如果这个号已经被另一条在用档案占用，系统会拒绝。请先改掉其中一方的手机号。

> ⚠️ **到店次数由「已完成」的预约驱动。** 只「已到店」还没「已完成」的预约不计数；「取消」「爽约」也不计数。如果你觉得数字不对，先用「重算到店统计」跑一遍，还不对就说明预约状态确实和你想的不一样，去预约管理里核对。

> ⚠️ **顾客换手机号后要改档案，也要让顾客重新绑定。** 改完档案里的手机号后，顾客在小程序里的绑定关系还指向旧号；他需要重新授权一次新手机号，才能看到自己的会员卡。

> ⚠️ **小程序自动建的档案也要核对。** 顾客第一次在小程序授权手机号时，系统会按微信昵称自动建一条档案（可能叫「微信顾客0002」）。门店看到这种名字，建议主动改成真实姓名，方便后续找人。

## 常见问题

**Q：顾客说在小程序里绑定了，但我在这里搜不到他。**
A：两个原因：① 他的手机号和档案里的不一致；② 他授权后系统新建了一条档案，名字是微信昵称（例如「微信顾客0002」）。请用**手机号**搜，不要只搜姓名。

**Q：顾客的档案被我们删过，他现在小程序绑不上，怎么办？**
A：把「档案状态」筛成「已删除档案」→ 找到这条 → 点「恢复档案」→ 恢复成功后让顾客在小程序里重新授权一次手机号即可。

**Q：这个顾客我们只见过一次，删掉可以吗？**
A：如果他有一条已完成的预约，就删不掉（系统会告诉他/你有几条预约记录）。如果一次都没来过（建重复了、建错了），可以直接删。

**Q：能不能给同一个手机号建两条档案？**
A：不能，系统会直接拒绝。这也意味着**不能把一个手机号同时给两个顾客用**（例如夫妻共用一个号）——请让他们各自留号，或者只建一条档案、在备注里写清。

**Q：我把顾客的手机号改了，他的余额和积分会丢吗？**
A：不会，都在同一条档案上，改手机号不影响任何资产。

**Q：为什么列表里有些顾客的「会员号」是空的？**
A：说明这条档案还没正式入会（没有会员号）。会员号是在第一次充值 / 消费等会员账务动作时由系统补上的。只留了手机号但还没消费过的顾客，就会是空的。

**Q：顾客说「我上次消费怎么没给我算积分」？**
A：积分跟着**钱**走——收款成功时才累计，退款时会回减；服务本身完成不单独计分。请到「会员管理 → 会员详情 → 账务流水」看有没有「积分累计」或「消费」那一条流水。
