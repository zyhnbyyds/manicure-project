# 积分与优惠券

## 这个模块解决什么问题

两种「让顾客觉得划算」的手段：

- **积分**：消费就攒分，攒了能抵钱、能换项目——不用额外算活动，系统自动；
- **优惠券**：满 100 减 20 这类券，由门店发给顾客（或顾客在小程序自助领取）。

两个模块都遵守同一条底层原则：

> 💡 **积分跟着「钱」走，不跟着「服务完成」走。**
> 大白话：顾客**付钱的那一刻**才攒积分；只把服务做完、钱还没付，是不攒分的。同理，**退款的时候积分要按比例扣回去**。

| 前台           | 收银时用积分抵扣、试算抵扣上限                           | 随收银台权限                                         |

| 顾客（小程序） | 看积分、自助兑换、领券、看自己的券                       | —                                                    |

## 分步操作

### 一、积分是怎么攒起来的（累计）

- **规则**：消费 **1 元 = 1 分**（门店配置项默认值），按实收金额的**整元部分**计算；
- **时点**：**收款成功时**累计（不是服务完成时）；
- **举例**：
  - 现金收款 190 元 → 累计 **190 分**；
  - 收款 190.80 元 → 只算整元部分 → 累计 **190 分**；
  - 定金 60 元 + 尾款 130 元 → 分两次累计 → 60 + 130 = **190 分**（结果一样，但流水里是两条）；
- **退款时会扣回**：按退款金额等比例回减积分。如果顾客已经把积分花掉了、导致积分不够扣，系统会**先扣到 0**，剩下的差额记一条「手工调整」流水并备注「积分不足，人工确认（应扣 X，实扣 Y）」。**退款不会被积分不足挡住**——顾客优先。

会员的积分可以在「会员管理 → 会员详情 → 档案」里看到，格式是「积分 190（累计 320）」：括号外是**当前可用**，括号里是**历史累计**。

> 💡 大白话：「当前可用」是能花的钱，「累计」是攒过多少的总量（花掉也不减少）。想知道顾客攒了多少，看累计；想知道他还能抵多少，看可用。

### 二、积分抵扣（抵钱）

**汇率**：**100 分抵 1 元**（门店配置项默认值）。

**单笔上限**：最多抵**折后金额的 30%**（门店配置项默认值）。

**算法顺序**：先算等级折扣 → 再算积分抵扣 → 最后算应付金额。

**完整算例（务必看懂这个例子）**：

| 步骤                     | 计算                    | 结果                            |
| ------------------------ | ----------------------- | ------------------------------- |
| 项目原价                 | 200 元                  | 200.00                          |
| 等级优惠（金卡 9.5 折）  | 200 × 5%                | −10.00                          |
| **折后金额**             | 200 − 10                | **190.00**                      |
| 积分抵扣上限             | 190 × 30%               | 最多抵 **57.00 元**             |
| 抵 57 元需要多少积分     | 57 × 100                | **5700 分**                     |
| 情况 A：顾客有 6000 分   | 用 5700 分抵 57 元      | **应付 133.00 元**（余 300 分） |
| 情况 B：顾客只有 5000 分 | 只能抵 50 元（5000 分） | **应付 140.00 元**（余 0 分）   |

**在收银台怎么操作**：

1. 选好单据后，右栏找到「积分抵扣」，点「**试算上限**」；
2. 系统提示「最多可用 X 分，可抵 ¥Y」，并在下方写明「**100 分抵 1 元、单笔上限 30%，服务端复算为准**」；
3. 在「使用积分数」里填想用的积分数（可以填得比上限小）；
4. 正常提交收款即可。中间栏会显示「积分抵扣 −¥X」。

**另外还有一个「积分抵扣试算」入口**（在「会员管理」页）：可以选 1~3 个服务项目试算「本单最多可用积分」与「最多可抵扣金额」，提示语是「金额以服务端复算为准（折扣 → 抵扣，单笔抵扣上限 30%）」。

**规则约束**：

| 规则                     | 说明                                                                                  |
| ------------------------ | ------------------------------------------------------------------------------------- |
| 不足直接失败             | 顾客积分不够时不能「先欠着」或「抵一部分」，系统会提示「积分不足」                    |
| 抵扣按整百算             | 只有 100 的整数倍才会被扣掉；填了 5050 分，实际按 5000 分抵 50 元，多出来的 50 分不动 |
| 与次卡不能叠加           | 次卡核销金额为 0，本来就没得抵                                                        |
| **与优惠券同一单二选一** | 系统硬规则：「优惠券与积分抵扣不能同时使用」                                          |

### 三、积分兑换（换项目）

积分除了抵钱，还能直接换东西。系统的做法很巧妙：

> 💡 **兑换品直接对应一个「次卡卡种」。** 换一个项目 = 给顾客发一张 1 次的次卡。
> 大白话：兑换之后顾客不是拿到一张「券」，而是**卡里多了一次服务**，到店核销即可，和买的次卡用起来完全一样。

**第一步：维护兑换品**

打开「积分兑换品」页（副标题：「兑换后发放对应次卡；库存 -1 不限，每人限兑 0 不限」），点「新增兑换品」：

| 表单字段           | 怎么填                                | 系统提示                      |
| ------------------ | ------------------------------------- | ----------------------------- |
| 兑换品名称         | 必填，占位「如 1000 积分兑 1 次美甲」 | —                             |
| 对应卡种           | 必填，兑换后发放的次卡卡种            | 「请选择卡种」                |
| 所需积分           | 必填，必须大于 0                      | 「必须大于 0」                |
| 库存               | 默认 **-1**                           | 「-1 = 不限库存；0 = 已兑完」 |
| 每人限兑           | 默认 **0**                            | 「0 = 不限」                  |
| 状态 / 排序 / 备注 | 状态默认启用                          | —                             |

列表里「库存」列：负数显示「不限」，0 显示「**0（已兑完）**」并标红，否则显示具体数字。

系统预置了两个兑换品：

| 兑换品名称     | 对应卡种                   | 所需积分 | 库存 | 每人限兑 |
| -------------- | -------------------------- | -------- | ---- | -------- |
| 纯色美甲体验卡 | 纯色美甲单次卡（售价 ¥88） | 8800 分  | 不限 | 1 次     |
| 手部护理体验卡 | 手部护理单次卡（售价 ¥68） | 6800 分  | 不限 | 2 次     |

> 💡 设计上的小心思：8800 分 ≈ 88 元（100 分抵 1 元），正好等于那个卡种的售价。**这样顾客不会用积分「贱买」服务**，门店也不吃亏。调整兑换积分时建议保持这个等价关系。

**第二步：给顾客兑换**

- 路径一：「积分兑换品」→ 右上角「**兑换记录**」；
- 路径二：「会员管理」→ 会员详情 →「**积分兑换**」。

在「会员管理」里的兑换弹窗会显示：「当前积分 X；兑换品直接指向卡种，兑换成功后立即发一张次卡。」选好兑换品 → 点「兑换」→ 确认窗「将扣除 X 积分并发放一张次卡（**同一事务完成，扣积分 + 发卡 + 写流水**）。确定兑换吗？」。

失败时的提示：「积分不足：当前 X 分，需要 Y 分」「积分兑换品已下架或已兑完」「已达每人限兑次数」。

**第三步：撤销兑换（兑错了）**

1. 打开「兑换记录」，筛出那条记录（状态「成功」才能撤销）；
2. 点「撤销兑换」；
3. 弹窗提示「撤销后**回补积分并作废对应次卡**，操作不可恢复」，**必须填写撤销原因**；
4. 确认后提示「已撤销兑换」。

### 四、手工调整积分（特殊情况）

1. 「会员管理」→ 会员详情 →「**调级/调积分**」；
2. 弹窗提示「当前等级：X，当前积分：N。**调整会写流水留痕，且会被「重算」覆盖。**」；
3. 填「积分增减」（**可正可负，例如 -100**）+ 「调整原因」（必填）；
4. 提交 → 确认窗提醒「手工调级会写 level_change 流水，且会被「重算」覆盖」。

> ⚠️ 手工调整只适合处理个案（例如补偿顾客）。它**会被重算覆盖**——重算是按流水重算余额、积分、累计消费与等级，人为加的分不在流水里，所以会被抹掉。想长期生效要改规则，不要改数字。

### 五、优惠券：先做模板

打开「优惠券模板」页，副标题一句话点题：**「模板是「以后还发不发」的开关；停用不影响顾客手里已有的券（面额与门槛在发券时已快照）」**。

点「新增券模板」：

| 表单字段           | 怎么填                                    | 系统提示                                  |
| ------------------ | ----------------------------------------- | ----------------------------------------- |
| 券名               | 必填，最多 50 字，占位「如 满 100 减 20」 | 「不能为空」「最多 50 字」                |
| 面额（元）         | 必填，必须大于 0                          | 「必须大于 0」                            |
| 门槛（元）         | 满多少才能用                              | 「**0 = 无门槛；应不小于面额**」          |
| 有效天数           | 从领取当天起算                            | 「从领取当天起算；0 = 长期有效」，默认 30 |
| 状态 / 排序 / 备注 | 备注「选填（仅后台可见）」                | —                                         |

列表里会显示「使用门槛」（`满 100 元` 或 `无门槛`）、「面额」（`¥20.00`）、「有效期」（`领取后 30 天` / `至 时间` / `长期有效`）、「**已发出**」（例如 `12 张`，方便知道发出去多少）。

保存时会被拦住的：「面额必须大于 0」「面额不应大于使用门槛」「生效时间不能晚于失效时间」「同名优惠券已存在」。

**下线一个券模板**：点「停用」，确认窗会写明「「满 100 减 20」已经发出 12 张。**停用只影响以后发放，顾客手里已有的券仍然可用**。确定停用吗？」

> 💡 大白话：停用券模板 = 「以后不再发这种券了」，不是「把顾客手里的券作废」。已经发出去的券，面额和门槛在**发券那一刻就抄下来了**，后面改模板也不会影响它。

### 六、优惠券：发券

1. 「会员管理」→ 找到顾客 → 点「**发券**」；
2. 选「券模板」（选项会显示「满 100 减 20（满 100 元减 20 元）」这样的格式）；
3. 点「发放」→ 提示「发券成功（可在会员详情核对）」。

**发券规则**：

| 情况                     | 结果                                                                   |
| ------------------------ | ---------------------------------------------------------------------- |
| 同一个顾客重复发同一张券 | **允许**（系统不做「已持有就拒绝」的限制）                             |
| 券模板已停用             | 拒绝：「该优惠券已停用，不能发放」                                     |
| 顾客在小程序自助领券     | 可以，但**同一张券已经有一张可用的**时会被拒绝：「你已经领过这张券了」 |

券号由系统生成，形如 `X20260101001`。

### 七、优惠券：怎么用（核销）

顾客的券在小程序「我的优惠券」里能看到，分三个页签：**可使用 / 已使用 / 已过期**。

**用券的规则**（系统里的实际口径）：

| 规则                                     | 说明                                                          |
| ---------------------------------------- | ------------------------------------------------------------- |
| 门槛按**等级折扣之后**的金额判断         | 例如原价 110、等级优惠 10 → 折后 100 → 「满 100 减 20」可以用 |
| 抵扣金额 = 面额与折后金额取小            | 折后 15 元、券面额 20 元 → 最多只能抵 15 元（不会变成负账）   |
| **不能与积分抵扣同时用**                 | 系统硬规则：「优惠券与积分抵扣不能同时使用」                  |
| **不能与次卡叠加**                       | 「使用次卡时不能叠加优惠券」                                  |
| 每单限用一张                             | 券不可叠加使用                                                |
| 用券必须在**下单建单的同一个动作**里完成 | 系统会把券标记为「已使用」并绑定到那张单上，防止重复使用      |

**重要说明（当前版本的操作入口）**：

- 用券的动作发生在**建单**时。目前**后台收银台没有「选择优惠券」这一栏**——收银台只处理「积分抵扣」；
- 后台页面能做的事情是：**维护券模板**（优惠券模板页）和**给会员发券**（会员管理 → 发券）；
- 顾客侧的券在**小程序**里能看到，自助下单时可以带券使用（小程序自助下单接口支持传券，与积分二选一）。

> ⚠️ 所以：如果顾客拿着券到店要当场抵扣，而这张单不是从小程序下单的，**系统里没有让收银台直接核销这张券的入口**。请按门店自己的变通办法处理（例如改用「手动改价」并填原因，或让顾客通过小程序下单），并在备注里写清用了哪张券。

## 字段说明

| -------------------------------- | ------ | ---------------------------- | ------------------------------------------------------------------------------- |
| 使用积分数（收银台）             | 否     | 本单用多少积分抵扣           | 填负数 → 「积分抵扣数不能为负」；超过上限的部分由系统夹取；积分不足时收款会失败 |
| 兑换品名称 / 对应卡种 / 所需积分 | 是     | 见上文                       | 「请选择对应卡种」「必须大于 0」「兑换品名称已存在」                            |

| 每人限兑                         | 否     | **0 = 不限**                 | 同上：「每人限兑必须是 0（不限）或正整数」                                      |

| 券名 / 面额（元）                | 是     | 券的显示名与抵扣金额         | 「名称不能为空」「面额必须大于 0」                                              |
| 门槛（元）                       | 否     | 0 = 无门槛                   | 门槛小于面额会被拦：「面额不应大于使用门槛」                                    |
| 有效天数                         | 否     | 从领取当天算起；0 = 长期有效 | 填 0 且模板没有绝对有效期时，券显示「长期有效」                                 |
| 积分增减（手工调整）             | 二选一 | 可正可负，例如 -100          | 「请选择目标等级或填写积分增减量」                                              |
| 调整原因（手工调整）             | **是** | 为什么调                     | 「调整原因必填」/「手工调整必须填写原因」                                       |

## 使用注意事项

> ⚠️ **积分只在「收到钱」时累计。** 定金收 60 元就攒 60 分，尾款收到再攒剩下的部分。只完成服务不收钱，积分不增加。

> ⚠️ **退款会把积分扣回去。** 退款成功后系统按比例回减积分；如果顾客已经花掉了这些积分，系统会先扣到 0，差额记一条「手工调整」流水并注明「积分不足，人工确认」。**退款本身不会被积分不足挡住。**

> ⚠️ **积分抵扣有 30% 的上限，不能一单抵到 0。** 上限按**折后金额**算，所以等级折扣越狠、可抵的绝对金额越小。前台不要凭感觉答应顾客「用积分全抵」。

> ⚠️ **券和积分只能二选一。** 系统会直接拒绝「同时使用」。前台在跟顾客沟通时说清：要么用券，要么用积分，选划算的那个。

> ⚠️ **取消/退款后，券不会自动退回。** 券在下单时就被标记为「已使用」并绑定了那张单。取消订单后券的状态需要在业务上处理——**目前系统没有「取消订单自动退券」的机制**，请前台在取消前先跟顾客说明，必要时由店长补发一张新券。

> ⚠️ **停用券模板不会作废已发出的券。** 想让手里的券失效，目前只能等它过期（有效期到期后系统自动标记为「已过期」）。所以**发券前想清楚有效期**，别一次性发一堆长期有效的券。

> ⚠️ **兑换积分要和卡种售价对得上，别把服务贱卖了。** 8800 分 = 88 元、正好等于「纯色美甲单次卡」的售价，这是刻意设的。改兑换积分时要一起看卡种售价。

> ⚠️ **撤销兑换会作废那张卡。** 如果顾客已经拿这张卡核销过了，撤销会出问题（卡已经不是「生效中」）。撤销前先确认这张卡**一次都没用过**。

> ⚠️ **手工调整积分会被重算覆盖。** 界面上的提示原文是「调整会写流水留痕，且会被「重算」覆盖」。补偿性加分请同时记好原因，并知道它可能消失。

> ⚠️ **小程序里看到的积分与券是服务端事实。** 顾客在小程序「积分兑换」页能自助兑换（「还差 N 积分，再攒攒～」是积分不足时的提示），「会员卡」页能领券。但**小程序充值还没开通**，别把「积分兑换」和「充值」混为一谈。

## 常见问题

**Q：顾客消费了 190 元，能攒多少分？**
A：190 分（1 元 1 分，按整元算）。如果是「定金 60 + 尾款 130」，会分两次各攒 60 分和 130 分，合计还是 190 分。

**Q：100 分抵 1 元，那 5700 分能抵多少钱？**
A：57 元。举例：原价 200 元、金卡 9.5 折 → 折后 190 元；抵扣上限 30% = 57 元 = 5700 分 → 最后应付 133 元。

**Q：顾客有 10000 分，能一次全用掉吗？**
A：不能。单笔抵扣上限是折后金额的 30%。折后 190 元的话最多抵 57 元（5700 分），剩下的积分留着下次用。

**Q：顾客想把积分换成现金，可以吗？**
A：不可以。积分只能抵扣消费或兑换兑换品，**不能提现、不能换现金**。

**Q：积分兑换之后拿到的是什么？**
A：一张对应卡种的次卡（例如「纯色美甲单次卡」，1 次）。到店做该项目时，在收银台用「次卡核销」核销即可，和买的次卡一样。

**Q：我发的券顾客说没收到，怎么办？**
A：先确认券是发给了哪条档案（是不是发到了另一个手机号的档案上）。然后让顾客在小程序「我的优惠券」里刷新查看；如果券已过期，会显示在「已过期」页签里。

**Q：券的「满 100 减 20」，是看原价还是折后价？**
A：看**等级折扣之后**的金额。举例：原价 110 元、金卡 9.5 折优惠 10 元 → 折后 100 元 → 这张券可以用（刚好满 100）。

**Q：为什么前台用不了顾客的券？**
A：当前版本后台收银台没有选择优惠券的入口，券的核销入口在建单时（目前是顾客小程序自助下单带券）。请按门店变通办法处理并写清备注，或让顾客通过小程序下单。

**Q：同名券模板建两次可以吗？**
A：不可以，系统会提示「同名优惠券已存在」。同一个券模板可以发给很多顾客，不需要建多个同名模板。
