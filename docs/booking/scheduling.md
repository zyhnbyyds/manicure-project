## 这个模块解决什么问题

排班决定**谁什么时候上班**，而"可约时段"是在班次的基础上算出来的：

```
当天班次 − 已有预约（含缓冲） = 顾客能约到的时段
```

所以排班是预约的前提。班上没排，那天就一个时段都查不出来；班上排得太宽，反而会被约到你不方便的时间。

排班管理由两部分组成：

- **周模板**：每周固定重复的班次（例如"周二到周日 10:00–19:00，周一休息"）；
- **日期例外**：某一天的特殊情况——整天请假，或者当天改成别的时段。

## 谁来用（适用角色）

| 谁 | 该做什么 | 权限 |
| --- | --- | --- |
| **店长** | 定每周固定班次、批请假、处理排班改动撞单 | 需要「排班管理-查看」与「排班管理-修改」两个权限点 |
| **前台** | 日常加请假、临时调班 | 建议只给"查看"，改班次由店长做 |
| **美甲师** | 只能在小程序工作台看自己当天的班次，看不到也改不了别人的 | 工作台不需要后台排班权限 |

> ⚠️ **不要给美甲师"排班管理-修改"权限。** 那个页面的编辑器是"整体替换某位美甲师的整周班次"，权限给出去后，他可以把同事的班次一起改掉。

## 操作路径

后台管理端 → 左侧菜单「美甲预约」→「排班管理」，或直接访问 `/biz/schedules`。

页面顶部先**选一位美甲师**，下面的所有内容都是这位美甲师的：切标签看「周模板」或「日期例外」。

## 分步操作

### 配周模板

1. 顶部「美甲师」下拉里选中要配的人；
2. 在「周模板」标签里，表格按周一~周日列出当前班次；没排班的那天显示"休息"；
3. 点某一天右侧的**铅笔图标**，弹出"编辑 周X 的班次"；
4. 填这一天的时段：**开始 10:00 ~ 结束 19:00**；
   - 一天要分成上午 / 下午，点「添加时段」再加一段（例如 10:00–12:00 与 13:00–20:00）；
   - 某一天不上班，就把这一天的时段**全部清空**（清空 = 该天休息）；
5. 点「保存周模板」。

> 💡 **"整体替换"是什么意思**：保存时系统会用你编辑后的结果**覆盖这位美甲师的整周排班**，而不是只改你动过的那一天。所以保存前请确认整周都是你想要的样子。

6. 保存成功会提示"周模板已保存"。如果弹出"有预约会落在新班次之外"，说明改动撞到了已有预约，见下方注意事项。

### 加请假（整天休息）

1. 切到「日期例外」标签；
2. 可以用"起始日 ~ 结束日"筛选查看已有的例外；
3. 点右上「新增例外」；
4. 类型选**「请假（整天休息）」**；
5. 选日期（一次一天，多天就加多条）；
6. 原因可填（例如"调休"、"外出培训"），建议填，事后好查；
7. 点「保存」。

保存后，这位美甲师**那一天整天都约不到**（查询可约时段会提示"该美甲师当天请假"）。

### 加自定义时段（加班 / 临时改时间）

1. 「新增例外」→ 类型选**「自定义时段（加班 / 调整）」**；
2. 选日期，填开始时间与结束时间（例如 13:00 ~ 21:00）；
3. 填原因，点「保存」。

> 💡 **自定义时段是"替代"，不是"叠加"**：这一天生效的时段完全以你填的为准，**周模板那一天原来的班次全部作废**。所以"今天上午照常、下午早点收工"这种需求，不是只填下午一段，而是把这一天的**全部**时段都写出来（例如 10:00–12:00 与 13:00–17:00）。

### 删掉某条例外

在「日期例外」列表里点该行右侧的删除图标，确认后删除。删除后这一天会**回到周模板的班次**（如果那天有请假记录被删掉，当天就恢复上班）。

如果删除会让已有预约"落在班次之外"，系统同样会先弹受影响清单。

## 字段说明

### 周模板

| 字段 | 必填 | 说明 | 填错会怎样 |
| --- | --- | --- | --- |
| 星期 | 是 | 周一~周日（系统按周一到周日 7 天展示，未填的天即休息） | 填错星期，可约时段整周错位 |
| 开始时间 | 是 | 当天上班时刻，例如 10:00 | 晚于结束时间会被拒绝 |
| 结束时间 | 是 | 当天下班时刻，例如 19:00 | 与开始时间填反会被拒绝 |
| 一天多段 | 否 | 同一天可以有多段（上午 / 下午），各段之间**不能重叠** | 段与段重叠会被拒绝（提示"存在重叠"） |

### 日期例外

| 字段 | 必填 | 说明 | 填错会怎样 |
| --- | --- | --- | --- |
| 类型 | 是 | 「请假（整天休息）」或「自定义时段（加班 / 调整）」 | 选错类型语义完全相反：请假→约不到；自定义→用新时段替代周模板 |
| 日期 | 是 | 生效的那一天 | 填错日期，那天不该休息却休息了 |
| 开始时间 | 选"自定义时段"时必填 | 当天新的上班时刻 | 请假类型填了时间会被拒绝（避免"既请假又上班"） |
| 结束时间 | 选"自定义时段"时必填 | 当天新的下班时刻 | 必须晚于开始时间，否则被拒绝 |
| 原因 | 建议填 | 例如 调休 / 外出培训 / 店休 | 不填也能保存，但事后不好追溯 |

## 使用注意事项

> ⚠️ **给某天加请假，会被"那天已有的预约"拦住。这条保护不能绕过。** 触发条件：该美甲师这一天已经存在"待确认 / 已确认 / 已到店"的预约。后果：系统弹出"有预约会落在新班次之外"，列出受影响的单号、顾客与时间，并**拒绝保存**。正确做法：先在「预约管理」里把这些单子改期或取消，再回来保存；如果确实要保留，可以在弹窗里点「确认强制保存」——但要让这些顾客另行通知，系统**不会**替你通知。

> ⚠️ **周模板的改动没有任何"强制"按钮。** 触发条件：缩短或删掉某天的班次，导致**未来 30 天内**已有预约落在班次外。后果：保存被拒绝，弹窗只有「知道了」，必须先去改期。正确做法：先改期，再改模板。（周模板是长期生效的骨架，系统刻意不给强制的口子。）

> ⚠️ **请假不会自动取消已有预约，也不会自动通知顾客。** 触发条件：用"强制保存"把请假加上去了。后果：那些单子依然存在、依然显示"已确认"，但已经落在班次之外，顾客那边也不会收到任何取消通知。正确做法：强制保存后立刻逐单改期或取消，改期/取消的动作才会触发给顾客的通知。

> ⚠️ **周模板的保护只覆盖未来 30 天。** 触发条件：某位美甲师 45 天后已经有一张预约，你现在缩短周模板。后果：这张单**不会**出现在冲突清单里（它的班次仍然按新模板生效，等于落在班次外），事后只能手工发现。正确做法：改模板后，用「预约管理」按区间翻一下一个月以后的单子。

> ⚠️ **自定义时段要多段就全部写出来。** 触发条件：只填了下午一段，以为上午还是周模板的班次。后果：这一天上午直接约不到。正确做法：把当天真正上班的每一段都填上。

> ⚠️ **同一天不能有两条"请假"。** 触发条件：重复给同一天加请假。后果：被拒绝并提示"该日已存在请假记录"。正确做法：多天请假就一天一条，日期不同即可。

> ⚠️ **班次不能跨零点。** 触发条件：想做"21:00 到次日 01:00"的夜班。后果：结束时间必须晚于开始时间，跨零点的写法保存不了。正确做法：把营业时间控制在同一天内；跨零点营业目前需要拆成两天的班次表达。

> ⚠️ **改班次不影响历史单。** 触发条件：改了周模板以后翻看昨天的单子。后果：昨天已完成的单子时间不会变（本来就是事实）。正确做法：这属于正常现象，不需要处理。

## 常见问题

**Q：为什么我保存周模板时被拒绝，但弹窗里没有"强制保存"按钮？**
A：周模板保存刻意只提示、不提供强制。请先到「预约管理」处理清单里的单子（改期或取消），再回来保存。

**Q：加请假时弹窗里的"确认强制保存"要不要点？**
A：只有在"这些顾客我会另行通知、也接受他们落在班次外"时才点。点了以后系统不会自动改期、也不会自动通知，需要你逐单处理。

**Q：请假和自定义时段同时存在会怎样？**
A：请假优先。只要那一天有请假记录，无论有没有自定义时段，那天都不可约。

**Q：能不能给一位美甲师排"每周只上两天"？**
A：可以。周模板里只填那两天的时段，其余天留空即可。

**Q：美甲师手机上看到的"今天休息"是哪来的？**
A：来自这里配置的请假与周模板。工作台会显示当天的生效班次，请假当天显示"今天休息"。详见 [美甲师工作台](./staff-workbench.md)。

**Q：现在改班次，会不会把已经生成好的周期预约也一起改掉？**
A：不会。周期预约已经生成的单子是独立的事实单，改班次只影响"以后还能约到什么时间"。改了班次后，未来那些落在班次外的周期单会被冲突保护提示出来。
