title: 美甲师工作台：手机上的排班卡与打卡机
---

## 这个模块解决什么问题

美甲师平时在工位上，不方便跑到前台电脑前操作。工作台让他在**自己的手机**上完成三件事：

1. 看**今天上什么班**、今天有几单分别几点；
2. **点到店**和**点完成**（完成后立刻计提成）；
3. 看自己这个月的**业绩、提成明细和顾客评价**。

它用的是同一份小程序，只是切换成"工作台模式"。

## 谁来用（适用角色）

| 谁         | 在哪儿做什么                                                                   |
| ---------- | ------------------------------------------------------------------------------ |
| **美甲师** | 手机上申请开通、进工作台看日程、点到店 / 完成、看业绩与评价                    |
| **店长**   | 后台「工作台授权」审批开通 / 驳回；停用档案即撤权                              |
| **前台**   | 不需要用工作台；但要知道"美甲师点了到店"和"前台点了到店"效果一样，避免重复处理 |

工作台里**只能看到本人的预约**，看不到同事的单，也看不到全店收入。

## 操作路径

**美甲师侧**（微信小程序）：

- 打开小程序 → 底部「我的」→ 找到"美甲师工作台"这一块 → 点「进入工作台」（已开通时）或「申请开通」；

**店长侧**（后台管理端）：

- 左侧菜单「美甲预约」→「工作台授权」，或直接访问 `/biz/app-staff-grants`。

## 分步操作

### 一、美甲师申请开通

1. 先在小程序里**绑定手机号**（没绑手机号不能申请，会提示"请先完成手机号授权，再申请美甲师工作台"）；
2. 进「我的」页面，在"美甲师工作台"这一块点申请；
3. 系统会用这个手机号去匹配**在职**的美甲师档案；
   - 匹配不到会提示"该手机号未匹配到在职美甲师档案，请联系门店处理"——这通常意味着档案里的电话填错了，或这个人还没建档；
4. 匹配成功后会提交申请，提示"申请已提交，等店长确认～"。

在「我的」页面上会一直显示当前状态：

| 显示文案                         | 含义                         |
| -------------------------------- | ---------------------------- |
| 已提交申请，等店长确认后就能用啦 | 申请已提交，等店长处理       |
| 已开通，可切换到工作台模式       | 可以用工作台了               |
| 申请被驳回了，可以重新提交一次   | 上次被驳回，可以再申请       |
| （什么都没有）                   | 从没申请过，页面不显示这一块 |

### 二、店长审批

1. 打开「工作台授权」，默认筛选"待确认"；
2. 核对每一行：**微信身份、手机号、匹配档案**；
   - 如果"匹配档案"显示成红色并带"（档案不可用）"，说明那位美甲师的档案已停用或已删除，这时批准也会被拒绝；
3. 点勾「通过」，确认框会再问一次："确定给「XXX」开通美甲师工作台吗？开通后 TA 可以在小程序看到自己的预约与业绩。"；
4. 点叉「驳回」，**必须填原因**（申请人能看到这句话），例如"手机号与档案不符，请联系店长"。

### 三、切换到工作台模式

开通后，在「我的」里点「进入工作台」，底部菜单会整套换成：

| 模式       | 底部菜单                 |
| ---------- | ------------------------ |
| 顾客模式   | 首页 / 预约 / 我的       |
| 工作台模式 | 工作台 / 我的预约 / 我的 |

工作台首页里有一个「顾客模式」入口，可以随时切回去自己当顾客用（约自己的单、看自己的余额积分）。

### 四、工作台首页看什么

打开工作台，一屏四块：

1. **顶部渐变卡**：自己的昵称、简介、**今日班次**（例如"10:00-19:00"，休息时显示"今天休息"）和今天的日期；
2. **今日业绩**（其实是**本月**的口径）：服务收入、完成单量、已计提成；下面一行小字是"已结算 X 元 · 评分 Y"。右上角显示当前月份，点它可以进业绩明细页；
3. **功能入口**：我的预约、业绩明细、我的评价、顾客模式；
4. **今日待服务**：今天排到的单，逐条显示时间、状态、顾客姓名、脱敏手机号、项目、共多少分钟、应付多少（还有待付时会单独标出）、备注；
   - 有电话的单显示「拨号」按钮，能点到店的点「已到店」，已到店的点「完成服务」；
   - 没有单时显示"今天还没有预约"；当天休息时显示"今天休息，好好放松一下"。

### 五、点到店与点完成

1. **点「已到店」**：顾客进门后点一下。再点一次不会出错（会提示"这单已经记过到店啦"）；
2. **点「完成服务」**：会先弹一个确认框："完成后会立即计提这一单的提成，确定吗？"；
3. 确认后如果尾款还没结清，屏幕会提示"尾款未结清，请到收银台催收"——这是提醒，不是失败；
4. 如果服务时间还没到，点完成会被拒绝，提示"服务尚未开始，不能提前标记完成"。

### 六、看我的预约（按日期翻）

「我的预约」页顶部是一条日期条，可以横向翻日期；下面按状态筛选。每条单显示时间、状态、顾客、脱敏手机号（点一下可以拨号）、项目与时长、备注、支付状态与金额，以及「顾客已到店」「服务完成」两个按钮。

### 七、看业绩与提成明细

「业绩明细」页上方可以切月份（上一月 / 下一月），汇总四个数字：

| 显示     | 含义                                         |
| -------- | -------------------------------------------- |
| 完成单量 | 这个月做完的单数                             |
| 实收合计 | 这些已完成单实际收到的钱                     |
| 待发     | 已计提、还没结算的提成                       |
| 已发     | 已经结算发放的提成                           |
| 已冲销   | 被冲销掉的提成（比如单子取消后冲回的）       |
| 评分     | 顾客评价的平均分（没有评价时显示"暂无评分"） |

下面是**逐单提成明细**：项目名、状态、单号、结算时间、计提基数、提成金额。

> 💡 **"基数"是什么**：这一单用来算提成的金额（通常是这单的实收），提成金额 = 基数 × 提成比例（+ 可能的固定额）。提成规则在后台「提成规则」里配，详见 [提成](../report/commission.md)。

### 八、看顾客评价

「我的评价」页显示顾客给的星级、日期、评价内容、门店的回复（如果有）和对应的单号。

**只显示已经公开的评价**：被门店隐藏的评价，本人也看不到（用于处理恶意或不当评价）。

## 字段说明

| 显示 / 字段          | 说明                                                                | 需要注意什么                                         |
| -------------------- | ------------------------------------------------------------------- | ---------------------------------------------------- |
| 今日班次             | 来自排班管理：当天的周模板班次，或那天的自定义时段                  | 显示"今天休息"说明那天有请假记录，或周模板本来就没排 |
| 状态                 | 与后台同一套状态：待确认 / 已确认 / 已到店 / 已完成 / 已取消 / 爽约 | 只有"已确认"能点到店，只有"已到店"能点完成           |
| 顾客手机号           | 列表里**只显示脱敏号码**，例如 `138****0001`                        | 想打电话时点「拨号」，系统才临时取一次真实号码       |
| 共 X 分钟            | 这一单各项目时长相加（不含缓冲）                                    | 缓冲时间不会显示在手机上                             |
| 应付 / 待付          | 应付金额与还没收的尾款                                              | 待付不为 0 时会单独标出，提醒顾客到前台结账          |
| 支付状态             | 未收款 / 部分收款 / 已结清 / 已退款 / 挂账                          | 与后台口径一致                                       |
| 服务收入             | 本月已完成单的实收合计                                              | 是"实收"，不是预付的定金                             |
| 待发 / 已发 / 已冲销 | 提成的三种状态：已计提未结算 / 已结算发放 / 被冲销                  | 已结算的提成不能冲销                                 |
| 评分                 | 已公开评价的平均分                                                  | 无评价时显示"暂无评分"，不是 0 分                    |
| 我的回复             | 门店在后台「评价管理」里回复的内容                                  | 美甲师自己不能回复，只能看                           |

## 使用注意事项

> ⚠️ **顾客手机号是"点一次取一次"，抓不到批量号码。** 触发条件：任何人（包括美甲师自己）想在手机上翻通讯录或批量看到顾客真号。后果：列表里永远是 `138****0001` 这样的脱敏格式；只有点「拨号」的那一瞬间才向系统取一次真实号码，而且**只能取本人名下的单**。这是有意设计的隐私保护。

> ⚠️ **工作台只能看自己的单。** 触发条件：想看同事今天的安排。后果：系统直接拒绝（不属于本人的单不会返回）。想看全店，请到前台电脑上的后台看。

> ⚠️ **店长停用档案 = 立刻收回工作台。** 触发条件：在后台把某位美甲师的状态关掉、或删除档案、或驳回申请。后果：他手机上会弹出"工作台已停用（档案停用或授权被撤），已切回顾客模式"，之后就看不到工作台内容了。正确做法：临时停岗可以用这个方式；恢复在职后需要重新申请或重新审批。

> ⚠️ **提前点「完成服务」会被拒绝。** 触发条件：预约的开始时间还没到就点完成。后果：提示"服务尚未开始，不能提前标记完成"。这是防止提前刷提成的保护。正确做法：服务真正结束后再点。

> ⚠️ **「完成服务」一旦点下就计提成。** 触发条件：点完成并确认。后果：提成当场产生；若这一单随后被取消，冲销受限制（已结算的提成不能冲销）。正确做法：确认服务确实做完、顾客没有异议再点。

> ⚠️ **忘了点「已到店」，系统会把顾客记成爽约。** 触发条件：单子仍是"已确认"，过了开始时间 + 容忍期（默认 15 分钟）。后果：单子自动变成"爽约"。正确做法：顾客一坐下就点「已到店」。

> ⚠️ **合同上写着"完成"的按钮不代表钱收齐了。** 触发条件：点了完成但顾客还没付尾款。后果：系统会提示"尾款未结清，请到收银台催收"，但不会阻止完成，也不会阻止计提成。正确做法：让顾客到前台把尾款结掉。

> ⚠️ **申请开通需要档案里手机号对得上，而且必须是在职状态。** 触发条件：门店换了美甲师的手机号却没更新档案，或档案里电话填错。后果：申请时提示匹配不到。正确做法：先到「美甲师」里核对电话，再让对方重新申请。

## 常见问题

**Q：美甲师在「我的」里看不到"美甲师工作台"这一块？**
A：说明这个微信身份从没申请过。让他先绑定手机号，再点申请；如果连申请入口都没有，检查是不是没绑定手机号。

**Q：店长点了「通过」，为什么他还是进不去？**
A：检查三件事：他手机号匹配到的那位美甲师档案是否在职、档案是否被删除、他的小程序是不是缓存了旧状态（让他退出登录后重新进小程序）。

**Q：一个微信能给两位美甲师开通工作台吗？**
A：不能。申请是用**当前微信绑定的手机号**去匹配档案的，一个身份对应一位美甲师。如果提示"当前美甲师授权与手机号档案不一致"，说明手机号换过或档案对不上，需要门店处理。

**Q：美甲师能看到顾客付了多少钱、用了什么方式吗？**
A：能看到这一单的应付与待付金额，但看不到门店的成本、其他美甲师的单，也看不到全店营收。

**Q：被驳回后还能再申请吗？**
A：可以。页面会显示"申请被驳回了，可以重新提交一次"。把问题解决（例如手机号改成档案里的号）后再申请。

**Q：我不想让他继续用工作台了，怎么处理最快？**
A：把这位美甲师的档案停用（或删除）。他的下一次操作就会被拒绝，并自动切回顾客模式。不需要单独做"取消授权"的操作。

**Q：业绩里的"服务收入"和后台报表里的营收对得上吗？**
A：口径不同：工作台显示的是这位美甲师**本月已完成单的实收**；后台报表是整店按营业日切分的净营收（成功收款 − 成功退款）。对账请以后台报表为准，详见 [报表详解](../report/reports.md)。
