## 这个模块解决什么问题

把一张预约单从头走到尾：**新建（含收定金或全款）→ 到店 → 完成 → 收尾款 → 需要时改期、取消、爽约、退款。**

这一页是预约管理页面每个按钮的详细操作说明，也是收钱时最常翻的一页。

## 谁来用（适用角色）

| 谁         | 做什么                                       | 需要的按钮权限                           |
| ---------- | -------------------------------------------- | ---------------------------------------- |
| **前台**   | 新建预约、到店、完成、改期、取消、爽约、收款 | 新建、改期、到店、完成、取消、爽约、收款 |
| **店长**   | 全部，另加改价、删除误录单、审批退款         | 上面全部 + 改价 + 删除 + 退款审批        |
| **美甲师** | 手机上点到店与完成（不用后台开单）           | 后台角色只给"列表 / 到店 / 完成"         |
| **顾客**   | 小程序自助预约与取消                         | 与后台无关                               |

## 操作路径

后台管理端 → 左侧菜单「美甲预约」→「预约管理」，或直接访问 `/biz/bookings`。

页面默认按**今天**筛选。上方筛选栏可以按"单日 / 区间""美甲师""服务状态""资金状态"以及"单号 / 顾客 / 手机号"关键字查找。

每一行最右侧有一排图标按钮，悬停会显示名称：详情、到店、完成服务、爽约、取消、结算 / 收尾款、改期 / 改美甲师、发起退款、软删。

## 分步操作

### 一、新建预约（后台开单）

点右上角「新建预约」，弹窗里从上往下五步走。

#### 1. 选择顾客

1. 在"姓名 / 手机号"输入框里搜索（也可以直接回车），点「搜索」；
2. 在右侧下拉里选中这位顾客。

> 💡 **首期不在开单弹窗里新建顾客**：弹窗只能**搜索并选择**已有顾客。如果这位顾客还没有档案，请先到「顾客档案」建好（姓名 + 手机号），再回来开单。这是为了避免收银时录错人。

选中顾客后，弹窗会显示他的**等级、折扣率、积分、储值余额**——这些会直接影响下面的算价。

#### 2. 选择服务项目

在"选择 1~3 个服务项目"下拉里勾选，最多 3 个。下面会实时显示**总时长**与**缓冲**，示例："总时长 90 分钟，缓冲 15 分钟"。

> 💡 **缓冲取所选项目的最大值**：一单里有多个项目时，时长相加、缓冲取最大的那个（不是相加）。

#### 3. 选美甲师、日期并查询可约时段

1. 选美甲师；
2. 选日期（默认今天）；
3. 点「查询可约时段」；
4. 从列出的时间按钮里点一个（显示"需连续 90 分钟 + 缓冲 15 分钟"）；
5. 选中的时间会在下方显示成"已选：10:00 - 11:30"。

如果查不到时段，页面会写明原因（请假 / 没排班 / 该美甲师不能做所选项目 / 已约满 / 超出可提前预约的天数）。**换美甲师、换日期或换项目组合再查**。

#### 4. 收款

上半部分是算价明细，从上到下依次是：

- 项目原价；
- 等级优惠（按顾客等级自动算，示例 9.5 折）；
- 积分抵扣（会显示"可用上限 X 分"，用了多少就显示抵多少）；
- 改价（有"改价"权限的人才会看到这一项）；
- **应付（服务端复算为准）**。

下半部分选收款方式：

1. **收款方式**选「收全款」或「收定金」；
   - 选「收定金」时会出现"定金（元）"输入框，**留空就按默认定金比例 30% 算**；
   - "本次应收"会实时显示：收全款 = 应付；收定金 = 定金值；
2. 在收款行里选**渠道**、填**金额（元）**；
   - 现金可以再填一个"实收"（顾客给整钱时用于记录找零）；
   - 选"次卡核销"要再选一张次卡；
3. 需要多种方式一起收，点「添加支付行」加一行，点行尾的垃圾桶删掉多余的行；
4. 点「按应收填充」可以把第一行自动填成本次应收；
5. 如果用了"挂账"，下面会出现"选择挂账主体"，**必须选**；
6. 需要抵积分就填"使用积分"；
7. 有改价权限的人可以填"改价（元）"（可正可负）与**改价原因**（必填）。

#### 5. 备注

填顾客需求或到店提醒（选填），例如"上次做的甲片，自带图样"。

最后点「提交预约」。成功后提示："创建成功：单号 B2026xxxx，应付 88.00，已收 26.40"。

### 二、顾客到店

在列表里找到这行，点「到店」图标。单子从"已确认"变成"已到店"。

- 美甲师也可以在自己的小程序工作台点「已到店」，效果一样；
- 已经点过的再点一次不会出错（会提示"这单已经记过到店啦"）。

### 三、完成服务

点「完成服务」图标。单子变成"已完成"，同时系统立刻：

- 给顾客档案加一次到店次数；
- 按提成规则计提这一单的提成；
- 给顾客发完成通知与评价邀请。

完成后如果尾款还没结清，页面会提醒"尾款未结清，请到收银台催收"。

### 四、结算 / 收尾款

点「结算 / 收尾款」图标，弹窗里显示：项目原价、等级优惠、积分抵扣、改价、**应付、已收、待收尾款**。

1. 需要追加积分抵扣，填"追加积分抵扣"（**只能增加，不能减少**，减少要走冲正流程）；
2. 在收款行里选渠道、填金额；
   - 点「按尾款填充」可以一次填满；
   - 同样是多行混合支付；
3. 如果用了挂账，选挂账主体；
4. 填结算备注（选填）；
5. 点「确认收款」，提示"结算完成：已收 88.00，尾款 0.00"。

> 💡 **混合支付是什么**：一张单可以用好几种方式一起付，例如"储值余额 50 元 + 现金 38 元"。系统的规则是：**所有收款行的合计不能超过本次应收（或待收尾款）**。

### 五、改期 / 改美甲师

点「改期 / 改美甲师」图标。弹窗顶部显示当前安排（美甲师、时间、时长、缓冲）。

1. 选新的美甲师（不改就保持原样）；
2. 选新日期；
3. 点「查询可约时段」，选一个时间；
4. 点「确认改期」。

改期只允许对"待确认 / 已确认"的单子做。改期成功时，如果**已收金额高于新的应付金额**，页面会提示：差额请到「退款审批」发起退款，**系统不做差额补收**。

### 六、取消

点「取消」图标（需填原因）：

- 如果这单**还没收过钱**，弹窗提示"取消后时段会立即释放，可被重新预约"；
- 如果这单**已经收过钱**（例如定金），弹窗会写明已收金额，并提示"取消后请到「退款审批」发起退款，退款不会自动发生"。

填原因（必填，最多 200 字）后点「确认」。

### 七、爽约

点「爽约」图标（需填原因）。弹窗提示"爽约会记录到顾客档案；若已收定金，需另行发起退款"。填原因后确认。

爽约只能对"已确认"的单子做。

### 八、发起退款（提交即执行）

点「发起退款」图标，弹窗先做**阶段试算**：

- 当前时间在预约开始时间之前还是之后 → 决定这笔退款按哪套规矩办；
- 距预约开始多少小时；
- 已收 / 已退、可退上限；
- 建议退款额（服务开始前 = 全额；服务中 = 0，等店长填）；
- 按旧判责规则算出的参考值（仅供参考）；
- 下面列出每张支付单的可退金额。

| 阶段                   | 金额                            | 谁能退                          |
| ---------------------- | ------------------------------- | ------------------------------- |
| **服务开始前**         | 系统锁定为**全额**，改不了      | 任何能进退款弹窗的人            |
| **服务中**（含已完成） | **店长手动填**，上限 = 可退上限 | 需「退款审批-审批」权限（店长） |

选退款去向（原路退回 / 现金退款 / 退入储值余额）、填退款原因（必填），提交 → 二次确认后系统**当场执行退款**（提示「退款已执行」），**没有待审批环节**。

渠道退款失败时单据停在「退款失败」，可在左侧菜单「美甲预约 → 退款审批」里点「重试执行」重新发起。

### 九、软删（只用于清理误录）

点垃圾桶图标并确认。**已经收过钱的单子会被拒绝删除**，必须先走完退款；日常作废请用「取消」或「爽约」。

## 字段说明

| 字段            | 必填             | 说明                                                                                                      | 填错会怎样                                             |
| --------------- | ---------------- | --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| 顾客            | 是               | 只能从已有顾客档案里选                                                                                    | 不选会提示"请先搜索并选择顾客"                         |
| 服务项目        | 是               | 1~3 个；时长相加、缓冲取最大                                                                              | 超过 3 个会被拒绝；项目停用后不能选                    |
| 美甲师          | 是               | 决定可约时段与冲突判断                                                                                    | 选到"不能做该项目"的美甲师，查时段为空                 |
| 日期            | 是               | 按门店本地日期                                                                                            | 选到没排班的日期会查不到时段                           |
| 时段            | 是               | 必须从查出来的时段里选，不能手填                                                                          | 手填的时间不在允许范围内会被拒绝                       |
| 收款方式        | 是               | 「收全款」或「收定金」                                                                                    | 选"收全款"但没填满，提交会被拒绝                       |
| 定金（元）      | 否               | 留空按默认定金比例 30% 算                                                                                 | 填得比应付还多，系统会按应付封顶                       |
| 收款渠道        | 是               | 现金 / 微信（线下收款）/ 支付宝（线下收款）/ 微信 Native 扫码 / 支付宝当面付 / 储值余额 / 次卡核销 / 挂账 | 选在线扫码但通道没开通会报错（不会留下半截单据）       |
| 金额（元）      | 是               | 这一行收多少                                                                                              | 所有行合计超过本次应收会被拒绝                         |
| 实收（元）      | 否               | 只在现金时出现，用于记录找零                                                                              | 其它渠道的实收不能超过应收金额                         |
| 次卡            | 选次卡核销时必填 | 从该顾客启用中的卡里选                                                                                    | 不选会被拒绝；核销记录金额是 0                         |
| 挂账主体        | 用挂账时必填     | 顾客 / 公司 / 员工，额度显示在选项里                                                                      | 不选会被拒绝；挂账不产生实收                           |
| 使用积分        | 否               | 默认 100 积分抵 1 元，最多抵 30%                                                                          | 填超了系统按上限收敛，不会报错                         |
| 改价（元）      | 否               | 可正可负，直接加在应付上                                                                                  | 没有改价权限时这个入口不显示；有权限但没填原因会被拒绝 |
| 改价原因        | 改价时必填       | 会记在单据备注里                                                                                          | 不填会被拒绝                                           |
| 备注            | 否               | 顾客需求 / 到店提醒                                                                                       | 不影响金额与时段                                       |
| 取消 / 爽约原因 | 是               | 最多 200 字，会出现在给顾客的通知里                                                                       | 不填直接拒绝提交                                       |
| 退款原因        | 是               | 记在退款单上                                                                                              | 不填会被拒绝                                           |
| 退款去向        | 是               | 原路退回（仅在线支付）/ 现金退款 / 退入储值余额                                                           | 线下收的钱选"原路退回"退不出去                         |

列表里几个容易看不懂的列：

- **时间**：显示"月-日 时:分 - 结束时刻"；
- **时长**：显示成"服务时长+缓冲 分"，例如"60+15 分"；
- **渠道**：这一列显示的是渠道**代号**（如 `cash`、`balance,cash`、`wxpay_native`），多笔收款项用逗号连起来，不是中文名；
- **备注**：会把顾客备注、改价金额与原因、取消 / 爽约原因合并显示。

详情弹窗里的"支付单"表格，**用途**列显示"定金 / 尾款"，**状态**列显示的是系统代号：`success`（成功）、`pending`（待支付）、`closed`（已关闭）、`failed`（失败）。

## 使用注意事项

> ⚠️ **"收全款"必须真的收清。** 触发条件：收款方式选了「收全款」，但收款行合计小于本次应收。后果：提交被拒绝，提示"全款模式必须收清"。正确做法：要么把金额填满，要么改选「收定金」；挂账要**显式添加一行"挂账"**才算收清。

> ⚠️ **收款合计不能超过应收。** 触发条件：定金模式下把收款行填得比定金还多。后果：提交被拒绝（"收款金额超过下单应收金额"）。正确做法：按"本次应收"填，多余的留到结算时再收。

> ⚠️ **现金的"实收"和"金额"不是一回事。** 触发条件：顾客给 100 元、实际应收 88 元。后果：如果把 100 填进"金额"，这单的已收就多记了 12 元，报表会虚高。正确做法：金额填 88，实收填 100。

> ⚠️ **挂账不产生实收，别以为钱收到了。** 触发条件：收款行选了"挂账"并选了挂账主体。后果：单子的资金状态变成"挂账"，钱没到手，欠款进了应收台账；如果这一单里既有现金又有挂账，状态仍显示"挂账"（表示还有未收部分）。正确做法：按约定账期到「应收台账」销账。

> ⚠️ **次卡核销不会抵扣尾款。** 触发条件：在新建预约或结算时把"次卡核销"当成一种付款方式去填金额。后果：核销记录记的是**金额 0**，尾款不会因此减少（填的金额超过本次应收还会被直接拒绝）。正确做法：次卡的发放与核销在 [会员次卡](../member/recharge-cards.md) 与 [收银台操作](../payment/cashier.md) 处理，预约单的钱按现金 / 扫码 / 储值等渠道正常收。

> ⚠️ **改期差额只退不补。** 触发条件：改期后已收金额高于新的应付金额。后果：系统不提供"差额补收"，也不会自动退款，只给一句提示。正确做法：到「发起退款」提交退款申请，由店长审批退差额。

> ⚠️ **结算时积分抵扣只能加不能减。** 触发条件：在结算弹窗里想把之前抵过的积分改小。后果：被拒绝，提示"减少需走冲正流程"。正确做法：需要减少请走会员的冲正流程（见会员章节）。

> ⚠️ **取消 / 爽约不会自动退款，也不会自动把时段"退给"顾客。** 触发条件：已收定金的单子被取消。后果：单子状态变了、时段释放了，钱还挂在账上。正确做法：立即发起退款申请，并通知顾客。

> ⚠️ **在线扫码收款有 5 分钟时限。** 触发条件：选了"微信 Native 扫码 / 支付宝当面付"但顾客迟迟没付。后果：超时后支付单会被自动关闭（每分钟检查一次）。正确做法：让顾客重新扫一次，或换线下记账方式收款。

> ⚠️ **"完成"会立刻计提成，而且已结算的提成不能冲销。** 触发条件：还没做完就点「完成服务」。后果：提成当场产生；这一单后来取消时，若提成已经结算，就无法冲销。正确做法：服务真正结束后再点。提醒：美甲师在小程序上提前点会被系统拒绝，但后台没有这道时间护栏。

## 常见问题

**Q：为什么不让我在开单弹窗里新建顾客？**
A：这是有意的。开单时最怕录错人，所以只能选已有档案。请先到「顾客档案」新建（姓名 + 手机号），再回来开单。

**Q：提交时提示"该时段刚被占用，请重新选择"是什么意思？**
A：在你填单的这几分钟里，另一位同事或顾客把这个时段订走了。系统会保留你填的内容，并自动刷新可约时段，重新选一个即可。

**Q：提示"该顾客此时段已有预约"，可以强行创建吗？**
A：可以。确认不是重复录入（例如两位美甲师同时给同一位顾客做不同项目）后，点弹窗里的「确认强制创建」。正常情况下请先核对，避免给同一位顾客开出两张单。

**Q：定金收了 26.4 元，为什么列表显示"部分收款"？**
A：因为应付 88 元还没收齐。定金 + 尾款 = 应付，尾款收完后状态才会变成"已结清"。

**Q：能不能一次收两种方式？**
A：可以。点「添加支付行」加行，例如储值余额 50 + 现金 38。合计不能超过应收。

**Q：顾客临时改时间，我已经收过定金了，怎么操作？**
A：用「改期 / 改美甲师」，定金会跟着这张单走，不需要退也不用补（除非新的应付变低了，那才需要退差额）。

**Q：退款要多久到账？**
A：提交后**立即执行**（服务开始前无理由全额退；服务中由店长填金额后执行）。现金退款与退入储值余额是系统内立刻记账；原路退回还要看支付渠道的处理时间。详细规则见 [退款](../payment/refunds.md)。

**Q：单子找不到了？**
A：检查筛选条件（日期、美甲师、状态），再把关键字清空试试；也可能是被同事软删了（软删有记录可查）。
