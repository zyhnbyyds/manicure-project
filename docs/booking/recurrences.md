---
title: 周期预约：熟客固定档期自动生成
---

## 这个模块解决什么问题

有些顾客是"每周三下午 3 点"这种固定档期。如果每次都手工开单，一年要开 52 次，还容易漏。

「周期预约」让门店**只配一条规则**，系统就按规则**滚动生成**未来的预约单：创建规则时先立刻把最近一段时间的单子生成出来，之后每天凌晨自动往后补充。

## 谁来用（适用角色）

| 谁 | 做什么 |
| --- | --- |
| **店长 / 前台** | 新建与维护规则、处理冲突、暂停或停止规则 |
| **美甲师** | 不需要操作；冲突时会收到站内消息提醒（**前提是他的档案绑定了后台账号**） |
| **顾客** | 不直接操作，只是"被生成"预约 |

需要的权限：查看列表、新建、修改、删除四个权限点，建议只给店长和前台主管。

## 操作路径

后台管理端 → 左侧菜单「美甲预约」→「周期预约」，或直接访问 `/biz/recurrences`。

## 分步操作

### 一、新建一条周期规则

1. 点右上角「新增规则」；
2. 填表单（字段见下方表格），重点三项：
   - **星期几 + 开始时间**：例如周三 + 15:00；
   - **生效开始 / 生效结束**：生效结束留空表示"长期有效"；
   - **提前生成**：默认 30 天，意思是"每次最多往后生成 30 天内的单"；
3. 在表单下方看"**将要生成的日期（N 个）**"那片区域——系统会把这次要生成的日期全部列出来，**在提交前就能看到会生成几张单**；
4. 点「检查冲突」可以预检这些日期里有没有和已有预约撞车（撞到的日期会标红）；
5. 点「创建并生成」，会弹一次确认："本次将生成 N 个预约（周三 15:00），首次生成不收款。其中 X 个日期该美甲师已有同时段预约（按「跳过 / 通知」策略处理）。确认创建吗？"；
6. 确认后弹窗切换成**生成结果**：左边"生成成功 N"、右边"跳过（冲突 / 无班次）N"。

> 💡 **"首次生成不收款"是什么意思**：周期单按设计**不收定金、不收款**，生成出来就是"未收款"，到店做完再收。这是整套系统里唯一"创建时不收钱"的场景（手工开单默认要收款）。所以看到周期单的尾款等于应付，是正常的。

### 二、看这条规则生成了哪些单

在列表里点该行的「已生成预约」图标（日历图标），右侧抽屉会列出这条规则生成的所有单：单号、开始 / 结束时间、服务状态、支付状态、顾客。

### 三、暂停 / 恢复 / 停止 / 删除

| 操作 | 效果 |
| --- | --- |
| **暂停** | 以后不再生成新单，**已生成的单完全不受影响**。可以随时「恢复」 |
| **停止** | 终态，之后永远不再生成（已生成的单保留）。停止后不能再恢复，也不能再修改这条规则 |
| **删除** | 停止并把它从列表里去掉（软删），已生成的预约**保留**，只是不再挂在这条规则名下 |

### 四、改规则

点「编辑」修改内容后保存。**修改只影响以后生成的单，已经生成的预约一张都不会被改动**，页面也会提示"已更新（不回溯已生成的预约）"。

如果确实要改已经生成的单，请到「预约管理」**逐单改期**。

### 五、每天自动发生的生成

系统每天凌晨 3:15 自动检查所有"进行中"的规则，把窗口里还没有生成的日期补上（生成窗口 = 从今天或上次游标的次日，到"今天 + 提前生成天数"，且不超过生效结束日）。所以周期单是"滚动往前铺"的。

## 字段说明

| 字段 | 必填 | 说明 | 填错会怎样 |
| --- | --- | --- | --- |
| 规则名 | 否 | 例如"张女士每周三美甲"，不填就显示"#编号" | 不填不影响功能，但列表里不好认 |
| 顾客 | 是 | 从已有顾客档案里选 | 不选会被拒绝 |
| 美甲师 | 是 | 每次由这位美甲师服务 | 该美甲师必须能做所选项目，否则创建被拒绝 |
| 服务项目 | 是 | 可多选；顺序即服务顺序 | 一个都不选会被拒绝 |
| 星期几 | 是 | 周一~周日，一周一次 | 选错星期，生成的日期整批错位 |
| 开始时间 | 是 | 格式 `HH:mm`，例如 15:00 | 格式不对会被拒绝；填了店里没排班的时间，那天会生成失败或被跳过 |
| 生效开始 | 是 | 从哪天开始算 | 填今天之前的日期，系统仍会按"今天"起算 |
| 生效结束 | 否 | 留空 = 长期有效 | 填得早于生效开始会被拒绝 |
| 提前生成（天） | 是 | 1~365，默认 30 | 填太小，几天后就没单生成了（靠每天自动补）；填太大，远期时段容易被提前占满 |
| 冲突策略 | 是 | 「跳过冲突（skip）」或「照旧生成并通知（notify）」 | 见下方注意事项 |
| 备注 | 否 | 选填 | — |

**冲突策略的区别**（这是这个模块最需要理解的一项）：

| 策略 | 撞上已有预约时会怎样 |
| --- | --- |
| **跳过冲突** | 那天**不生成**这张单，同时在「通知记录」里留一条站内通知，方便人工补单 |
| **照旧生成并通知** | 那天**照样生成**这张单（与已有预约重叠），并把单据备注标成"周期生成·时段冲突待人工处理"，同时给美甲师发站内通知 |

## 使用注意事项

> ⚠️ **同一美甲师 + 同一星期几 + 同一开始时间只能有一条生效规则。** 触发条件：给同一个人的周三 15:00 又建了一条规则（包括作废后没停止的旧规则）。后果：创建被拒绝，提示"该美甲师在同一星期几同一开始时间已有周期规则（避免同一时段生成两单）"。正确做法：先把旧规则「停止」，或修改旧规则。

> ⚠️ **改规则不回溯，这个必须讲给顾客听。** 触发条件：顾客说"以后改成周四"，你直接编辑规则。后果：**已经生成的那些周三的单子还在**，顾客会照旧被安排在周三。正确做法：编辑规则改未来的档期，然后到「预约管理」把已经生成的、需要改的那几张单**逐单改期或取消**。

> ⚠️ **"照旧生成"会真的生成撞车的单。** 触发条件：冲突策略选了"照旧生成并通知"，而那天的时段已经有人订走了。后果：系统会生成一张与已有预约时间重叠的单（备注里带冲突标记），如果没人处理，到店那天就是两位顾客抢一个美甲师。正确做法：每天开店前扫一眼周期预约的冲突提醒，把带"待人工处理"标记的单子改期。

> ⚠️ **冲突通知发给美甲师的后台账号，没绑定就收不到。** 触发条件：这位美甲师的档案没有绑定后台账号，或者没有给相关角色开站内消息的查看入口。后果：冲突发生了但没人收到提醒。正确做法：给美甲师档案绑定后台账号，或每天自己看「通知记录」与「周期预约」列表。

> ⚠️ **生效结束日不要填错成年份。** 触发条件：想设一年，结果填成去年的日期。后果：规则创建后立刻到有效期终点，一天都不会生成，或只生成极少数几张单。正确做法：填之前核对年份；生效结束早于生效开始会被直接拒绝。

> ⚠️ **周期单不收预付款，收银时要留意。** 触发条件：前台以为"预约都收过定金了"。后果：做完服务发现一分钱没收，而且这些单不会出现在"已收定金"的统计里。正确做法：把这些单当作"到店结算"的单处理；界面上它们显示"未收款"，尾款等于应付。

> ⚠️ **暂停 ≠ 取消已生成的单。** 触发条件：顾客说出差了，你点了「暂停」。后果：以后不再生成，但已经生成、还没到店的那些单**照样存在**，顾客的档期还占着。正确做法：暂停规则后，逐单取消或改期已经生成的单。

> ⚠️ **「停止」是终态，不能恢复。** 触发条件：想临时停一下却点了「停止」。后果：这条规则永远不再生成，也不能再编辑，只能重新建一条。正确做法：临时停用请用「暂停」。

> ⚠️ **"撤销本窗口生成的单"当前在页面上没有入口。** 触发条件：想一键把这条规则刚生成的未收款单子撤回。后果：目前「周期预约」页面里只有"已生成预约"抽屉，底部明确写着该功能本期未实现。正确做法：逐单取消（不要的点「取消」并填原因），或联系技术人员处理。

## 常见问题

**Q：为什么创建后只生成了几张单，不是全年？**
A：周期单是**滚动生成**的，每次只铺"提前生成天数"（默认 30 天）以内的日期。剩下的由每天凌晨的自动任务往后补。想一次铺更远，就把"提前生成"改大。

**Q：预览里明明有 4 个日期，为什么只生成成功 3 张？**
A：剩下那天被跳过了。常见原因：那天美甲师请假或没排班（无班次），或者撞上了已有预约而策略是"跳过"。生成结果里"跳过"的数字就是它。

**Q：被跳过的那些天，系统会提醒我吗？**
A：会记一条站内通知（在「通知记录」里查）；如果策略是"照旧生成并通知"，生成出来的单子备注里会带"周期生成·时段冲突待人工处理"。无论哪种，都需要人工到「预约管理」补单或改期。

**Q：能不能配"每两周一次"或"每月 1 号"？**
A：目前的规则是"每周几 + 一个开始时间"，不支持隔周或按月。需要的话可以配多条规则交替使用，或手工开单。

**Q：一位顾客能有两条规则吗？**
A：可以，例如"每周三 15:00"和"每周六 10:00"各一条。同一美甲师同一星期几同一时间的重复规则会被拒绝。

**Q：周期单可以改价、用券或用积分吗？**
A：规则生成时不支持这些（只按顾客等级折扣算，不叠加积分）。需要改价或加优惠，请在生成的单子上按手工单的方式处理（结算时追加积分抵扣、或由有权限的人改价）。

**Q：我想让这条规则今天立刻多生成一些单，怎么办？**
A：把"提前生成"改大后保存，下一次自动生成（每天凌晨 3:15）会按新窗口补。急需的话可以直接在「预约管理」手工开单。
