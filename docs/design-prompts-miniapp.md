# 小程序设计稿生成提示词（ChatGPT / 图像生成）

> **用途**：给 ChatGPT 逐页生成小程序 UI 设计稿。
> **前提**：这套提示词**刻意不复刻现有实现**（现有版本是 emoji + 粉 pastel 卡片堆叠，缺乏设计感）。
> 目标是先拿到「好看且可落地」的视觉方向，再倒推实现。
> **生成方式**：**一页一段，分开发**。每段都是自包含的（不依赖上下文记忆），保证你换会话、换账号也能复现同一风格。

---

## 0. 怎么用（先看这 5 条）

1. **先选方向**：看 §1 的三个方向，默认用 **A「柔光编辑」**。选定后**只改风格块、不改页面结构块**。
2. **一次一页**：把某页的整段提示词单独发给 ChatGPT，要求输出**一张竖版整屏设计稿**。
   建议比例 **9:19.5**（约 375×812pt，即 iPhone 竖屏）。
3. **让它出 3 版挑**：在提示词末尾加一句
   `请输出 3 个不同排版方案（同一风格、结构不变，只改布局节奏与图文比例）`。
4. **中文文字一定会糊**：图像模型对密集中文的渲染不可靠。两种处理：
   - 让它**只保留必要文字**（页面标题、价格、按钮），其余用小灰条示意；
   - 或者把 §4 的「文案表」单独发给它，明确要求按此文字排版；
   - 最终**用 Figma / 稿定把文案替换成清晰文本**，这才是能交付开发的稿。
5. **不要让它画手机外壳**：明确「只输出屏幕内容，不要 3D 手机样机、不要多屏拼接、不要投影底座」。

## 1. 设计方向（三选一）

### ✅ A. 柔光编辑 Soft Editorial（默认，推荐）

**为什么推荐**：美甲是「审美消费」，视觉上应当像一本生活方式杂志，而不是电商货架。
用**大留白 + 大图 + 衬线标题 + 极轻阴影**建立高级感，同时保留暖调与柔和圆角，不冷、不硬。

| 维度     | 规格                                                                                                                               |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 底色     | 暖奶油白 `#FBF7F4`；卡片纯白 `#FFFFFF`                                                                                             |
| 主色     | 玫瑰木 `#B8656B`（用于按钮、价格、选中态，**不大面积铺**）                                                                         |
| 辅色     | 奶油 `#F6EDE6`、藕粉 `#E8D3D0`（用于分层背景、标签底）                                                                             |
| 点睛色   | 香槟金 `#C8A96A`（**只用于细线、徽标、等级标识**，面积 < 3%）                                                                      |
| 正文色   | 墨褐 `#2E2724`；次要 `#7A6E68`；禁用 `#B9AEA8`                                                                                     |
| 描边     | `#EFE7E1` 1px（**优先用描边替代重阴影**）                                                                                          |
| 阴影     | `0 8px 30px rgba(46,39,36,0.06)`，只给浮起元素（底部操作条、弹层）                                                                 |
| 圆角     | 卡片 20–24px，按钮 999px（胶囊），图片 16px；**不要圆角堆叠**                                                                      |
| 字体     | 标题：**衬线**（思源宋体 / 宋体，字重 Medium–SemiBold，字距略松）；正文：无衬线（苹方 / 思源黑体）；价格数字：衬线或细体，字号放大 |
| 字号节奏 | 页面主标题 28pt / 区块标题 18pt / 正文 15pt / 辅助 12pt；行高 1.6                                                                  |
| 图片     | **真实美甲作品摄影为主体**（自然光、浅色调、留白），圆角 16px；**绝不用 emoji、不用矢量插画代替图片**                              |
| 图标     | 1.5px 细线图标，单色（墨褐或主色），**不用彩色 emoji**                                                                             |
| 留白     | 页面左右边距 20pt，区块间距 28–36pt（**敢留白**）                                                                                  |
| 层次手法 | 靠**字号对比 + 留白 + 1px 描边**建立层次，而不是靠阴影和色块                                                                       |

### B. 清透果冻 Juicy Glass（备选，更年轻潮流）

半透明玻璃卡（背景模糊）+ 柔和渐变光斑 + 大圆角（28px）+ 亮泽高光；
主色 `#FF7BA9` → `#FFB37B` 渐变，底色 `#FFF1F6`；标题用圆体（如思源柔黑），价格用超粗体；
图片仍然要真实摄影。**适合定位年轻客群、社媒传播**；缺点是易过时、对性能与实现要求更高。

### C. 黑白编辑 Monochrome（备选，最设计师向）

近黑白：底 `#FAFAF8`、文字 `#111111`、分隔线 `#E5E5E5`；
**只保留一个高饱和点睛色**（如 `#E8462D` 朱红或 `#3D5AFE` 电光蓝）用于价格与主按钮；
大字号衬线标题、极简图标、近乎无圆角（4–8px）、大量留白与细分隔线；
图片处理成统一色调（低饱和）。**适合做「设计品牌感」，但对内容摄影质量要求最高**。
