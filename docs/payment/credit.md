# 挂账与应收

## 这个模块解决什么问题

有些客人不是当场付钱：公司的员工福利月结、熟客先记账、员工内部消费。这类「先消费、后付钱」在系统里叫**挂账**。

挂账要管好三件事：

1. **谁可以挂**（挂账主体：顾客 / 公司 / 员工）；
2. **最多能挂多少**（额度）与**什么时候该还**（账期 / 到期日）；
3. **还钱时怎么记**（销账）。

还有一个很容易搞错的报表口径，必须一开始就记住：

> 💡 **挂账不计营收，销账才计入。**
> 大白话：挂账那天顾客一分钱没给，所以**不算今天赚到的钱**；等他来还钱、钱真的收到了，才算进营收。系统里所有收入都是「钱真的到账了」才算数。

## 谁来用（适用角色）

| 角色          | 能做什么                                                 |
| ------------- | -------------------------------------------------------- |
| 店长          | 维护挂账主体、给顾客挂账、销账、作废应收单、看账龄汇总   |
| 前台 / 收银员 | 在收银台选挂账主体给顾客挂账；**销账与作废建议只给店长** |
| 老板 / 财务   | 看「应收台账」的账龄汇总，跟进逾期欠款                   |

对应的权限点：

| 权限点（配角色时看到的项）         | 管什么                       |
| ---------------------------------- | ---------------------------- |
| 挂账主体-查询 / 新增 / 修改 / 删除 | 维护可挂账的主体             |
| 应收台账-查询                      | 看应收明细与账龄汇总         |
| 应收台账-销账                      | **收钱销账**（建议只给店长） |
| 应收台账-作废                      | 作废应收单（建议只给店长）   |

## 操作路径

两个页面配合使用：

| 页面     | 路径                                                           | 用途                             |
| -------- | -------------------------------------------------------------- | -------------------------------- |
| 挂账主体 | 后台 → 左侧菜单「美甲预约」→「挂账主体」`/biz/credit-accounts` | 维护谁能挂账、额度多少、几号结账 |
| 应收台账 | 后台 → 左侧菜单「美甲预约」→「应收台账」`/biz/receivables`     | 看一笔笔欠款、销账、作废、看账龄 |

给顾客挂账的动作在**收银台**（右栏渠道选「挂账」），不在这个页面。

## 分步操作

### 一、先建挂账主体

1. 打开「挂账主体」页，点右上角「**新增主体**」。
2. 填写表单：

| 表单字段 | 怎么填                                             | 提示原文                             |
| -------- | -------------------------------------------------- | ------------------------------------ |
| 主体名称 | 必填。占位提示「如 XX 公司 / 张三」                | 不能为空                             |
| 类型     | 顾客 / 公司 / 员工，默认「顾客」                   | —                                    |
| 关联顾客 | **只有类型选「顾客」时才出现**，从顾客档案里选     | 占位「请选择顾客」                   |
| 联系人   | 选填，例如「王经理」                               | 选填                                 |
| 联系电话 | 选填                                               | 选填                                 |
| 额度(元) | 填金额；**填 0 = 不限额度**                        | 「0 = 不限额度」                     |
| 月结日   | **1~28 之间的日号；填 0 = 不定期（应收无到期日）** | 「1~28，0 = 不定期（应收无到期日）」 |
| 状态     | 「启用 / 禁用」开关                                | —                                    |
| 备注     | 选填                                               | 选填                                 |

3. 点「保存」→ 提示「创建成功」。
4. 列表里能看到这个主体的「额度」「已挂未结」「可用额度」「月结日」：
   - 额度显示「不限」表示 0（不限额）；
   - 「已挂未结」大于 0 时会变橙色加粗（提醒你有人欠着钱）；
   - 「可用额度」≤ 0 时会变红色加粗（额度用满了，不能再挂）；
   - 月结日显示「每月 5 日」或「不定期」。

> 💡 大白话：**额度是「同时最多欠多少」，不是「总共能欠多少」**。公司额度 5000 元，挂了 4000 元之后只剩 1000 元可挂；等他们来销账 4000 元，额度又回到 5000 元。

系统里预置了两个示例主体（可以直接改成门店自己的）：

| 主体名称           | 类型 | 联系人 | 额度     | 月结日    | 备注                                    |
| ------------------ | ---- | ------ | -------- | --------- | --------------------------------------- |
| 某美妆公司（月结） | 公司 | 王经理 | ¥5000.00 | 每月 5 日 | 员工福利月结，额度 ¥5000，每月 5 日结算 |
| 员工内部挂账       | 员工 | 店长   | ¥1000.00 | 不定期    | 员工内部账，额度 ¥1000，不定期结算      |

### 二、下单挂账（在收银台）

1. 打开收银台，选好单据，在右栏点「添加一行」。
2. 这一行的渠道选「**挂账**」，金额填本次要赊的数额。
3. 下方出现「**挂账主体**」下拉，选项长这样：
   - 「某美妆公司（公司，剩余额度 ¥4800.00）」
   - 「员工内部挂账（员工，额度不限）」
4. 选好主体，点「去收款」→「确认收款」。
5. 结果：
   - 预约单的资金状态变成「**挂账**」；
   - 「应收台账」里自动生成一张应收单（单号形如 `A20260101001`）；
   - 主体的「已挂未结」增加，可用额度减少；
   - **不产生积分**（积分跟着钱走，钱还没收到）。

**挂账可以和别的收款方式叠加（部分挂账）**：例如应收 200 元，顾客先付 50 元现金，剩下 150 元挂账。做法是加两行：现金 50、挂账 150。系统会分别记一笔现金收款和一笔应收单。

挂账时会被拦住的几种情况：

| 情况                         | 系统提示                                         |
| ---------------------------- | ------------------------------------------------ |
| 超过额度                     | 「超出挂账额度，剩余 ¥X」                        |
| 两个人同时挂，撞在额度边上   | 「挂账额度不足或已被其它单据占用，请刷新后重试」 |
| 主体被改成「禁用」           | 「挂账主体已停用，不能挂账」                     |
| 没选主体                     | 「挂账必须选择挂账主体」（收银台提示）           |
| 顾客类型的主体不是这个顾客的 | 「该挂账主体不属于此顾客」                       |

### 三、销账（顾客 / 公司来还钱）

1. 打开「应收台账」，找到那张应收单（状态「未结」或「部分销账」）。
2. 点「**销账**」图标。
3. 弹窗顶部先给你一份实时账目，销账前一定要看：

| 显示项                                     | 意思                                     |
| ------------------------------------------ | ---------------------------------------- |
| 应收金额                                   | 这张单一共欠多少                         |
| 已销账                                     | 已经还了多少                             |
| 本次销账合计                               | 这次要还多少                             |
| 剩余应收                                   | 这次销完还剩多少                         |
| 主体额度 / 销账后已挂未结 / 销账后剩余额度 | 销完之后主体的额度占用情况（为负会标红） |
| 到期日 / 状态                              | 「不定期」表示没有账期                   |

4. 在「销账明细（支持多笔混合）」里添加还款方式：
   - 渠道可选：**现金 / 微信线下 / 支付宝线下 / 储值余额 / 微信扫码(在线) / 支付宝扫码(在线)**；
   - 每一笔填金额，可以填备注（选填）；
   - 点「**填剩余**」可以一键把这一笔填成剩余应收的金额，省得手算；
   - 可以「添加一笔」做混合收款（例如一半现金一半微信）。
5. 点「确认销账」→ 二次确认窗会列出每一笔的渠道与金额、合计、销账后剩余应收，并明确写着「**销账不得超额**，确认执行吗？」
6. 点「确认销账」提交，结果分两种：
   - **全部是线下 / 现金 / 储值渠道** → 立刻提示「销账成功，剩余应收 ¥X」或「销账成功，该应收已结清」；
   - **含在线扫码渠道** → 会弹出一个在线收款码，顾客扫码付款成功后才真正销账（提示原文：「含在线扫码渠道：提交后会生成收款二维码，顾客扫码支付成功后，在线支付单由回调 / 主动查单落地（**线上部分不会立即销账**）」）。
7. 销账记录随时可查：在应收单上点「销账记录」图标，可以看到渠道、金额、支付时间、备注。

**销账之后会发生什么**：

- 应收单状态变成「部分销账」或「已结清」；
- 主体的「已挂未结」减少，额度释放；
- 结清时，这张预约的资金状态在收银台变成已结清；
- **这时才累计顾客的消费与积分**（挂账那天不计）；
- 如果还款走的是在线扫码，**要等渠道确认收到钱才计入**。

### 四、作废应收单（挂错了、不用还了）

1. 在应收单上点「**作废**」图标（**只有一笔都没销过账的单子**才能作废，这个按钮在已销账的行上是灰的）。
2. 弹窗里会显示应收单号和金额，说明「作废后不可恢复，同时回减该主体的已挂未结金额」。
3. **填写作废原因（必填）**，点「确认作废」→ 提示「已作废」。
4. 作废后：状态变成「**已作废**」（列表里带删除线），主体的已挂未结金额同步回减，额度释放。

### 五、看账龄与逾期（老板 / 财务）

打开「应收台账」页，上方就是「**按主体聚合的账龄汇总**」（点任意一行可以只看该主体的应收明细）：

| 列名            | 意思                                 |
| --------------- | ------------------------------------ |
| 主体 / 类型     | 谁欠的钱                             |
| 额度 / 已挂未结 | 额度上限与实际占用                   |
| **应收余额**    | 还没收回来的总额                     |
| 0-30 天         | 账龄在这个区间的欠款                 |
| 31-60 天        | 账龄在这个区间的欠款                 |
| 60 天以上       | 拖得最久的欠款（颜色最深，最需要催） |
| 逾期金额        | 已过到期日还没还的金额               |
| 未结单数        | 还有几张单没结清                     |

账龄按**到期日**算（没有到期日的按挂账日期算），颜色是按该列最大金额做的深浅色阶——**颜色越深金额越大**，一眼就能看出谁是欠款大户。

**逾期是怎么来的**：系统每天凌晨 **01:10** 自动检查一遍，把「状态是未结或部分销账」且「到期日已经过了」的应收单标记为「**已逾期**」（列表里到期日会变红）。这个任务只改状态、不动金额。

**到期日是怎么算的**：主体的月结日是多少号，到期日就是**挂账之后第一个该日号**。举例：

- 主体月结日 = 5 日，1 月 20 日挂了账 → 1 月的 5 日已经过了，所以到期日是 **2 月 5 日**；
- 主体月结日 = 5 日，1 月 3 日挂了账 → 1 月的 5 日还没到，所以到期日是 **1 月 5 日**；
- 主体月结日 = 0（不定期）→ **没有到期日**，列表里显示「不定期」，也永远不会被标记逾期（但账龄照算）。

### 六、报表口径（重要，别报错数）

| 动作                           | 计入当日营收吗                             |
| ------------------------------ | ------------------------------------------ |
| 挂账（下单赊账）               | **不计入**。钱没到账，只是产生了一张应收单 |
| 销账（顾客还钱，且钱确实收到） | **计入**。这才是真正的收入                 |
| 销账走在线扫码但顾客还没付     | **不计入**。等渠道确认收到钱才计入         |
| 作废应收单                     | **不计入**（本来就没计过）                 |

> 💡 大白话：挂账是「白条」，销账是「白条兑现」。报表只认兑现。

## 使用注意事项

> ⚠️ **挂账不写支付单，这是刻意的。** 挂账那天顾客没有付钱，所以系统不会记一笔「收款」；只有销账、钱真的收到时才记。所以千万不要在收银台用「现金」记一笔挂账来「凑数字」——那会让报表虚高、也会让顾客以为已经付过钱。

> ⚠️ **销账不得超额。** 系统的规则是「销账金额 + 已销账金额 ≤ 应收金额」，多一分都不行。即使两个人同时点，也只有一个人会成功，另一个会提示「应收单已被其它销账操作更新，请刷新后重试」。看到这个提示**刷新后重新核对剩余金额**，不要重复提交。

> ⚠️ **在线扫码销账不会立刻销账。** 如果销账里含「微信扫码(在线) / 支付宝扫码(在线)」，提交后只是生成了一张在线支付单，**要等顾客真的付了钱**（渠道通知或系统主动查单确认）才销账、才计营收。顾客扫了码却没付，台账上仍然是欠着的。

> ⚠️ **作废只能在「一分钱都还没还」的时候做。** 已经销过账的应收单不能作废（按钮是灰的），因为作废后要把整单金额从主体占用里回减，已经还过钱的情况会算乱。还了一部分又想不要了，只能继续销账或用业务方式处理。

> ⚠️ **禁用主体不会让欠款消失。** 「禁用」只是不让它再用来挂账；已经产生的应收单照样要销账、照样会被标记逾期。禁用前请先把它下面的欠款清掉。

> ⚠️ **额度 0 是「不限」，不是「零」。** 首次建主体时如果没有把握，填 0 表示不限额；要控制风险就填一个具体金额，并在挂到额度上限时收到「超出挂账额度，剩余 ¥X」的提示。

> ⚠️ **改小额度会被已挂账金额挡住。** 想把一个已经欠了 4000 元的主体额度改成 3000 元，系统会拒绝（提示「挂账额度不能小于已挂账金额 ¥4000.00」）。必须先让它销账，再改额度。

> ⚠️ **挂账的钱没有「退款」，只有「作废」。** 因为它根本没收到钱。如果挂错了，用「作废应收单」处理，不要去找「退款」流程。

> ⚠️ **月结日算的是「之后第一个」，不是「本月第一个」。** 月底挂的账，到期日往往落到下个月。对账期敏感的门店，建议在给公司客户挂账前先确认清楚。

## 常见问题

**Q：公司客户说这个月挂的账下个月 5 号付，我要怎么配？**
A：新建一个「公司」类型的主体，月结日填 5。系统会自动把每笔挂账的到期日算成「挂账日之后第一个 5 号」，并在到期日之后把它标记为逾期。

**Q：收银台里挂账的「剩余额度」是怎么算的？**
A：额度 − 已挂未结。选主体时下拉里直接写着「某美妆公司（公司，剩余额度 ¥4800.00）」；额度为 0 的主体显示「额度不限」。

**Q：顾客一次性把欠款还清了，系统会给他加积分吗？**
A：会。**销账成功时**才累计消费与积分（挂账那天不计）。走在线扫码的，要等渠道确认收到钱才计。

**Q：欠款到期了系统会自动催款吗？**
A：系统会在每天凌晨 01:10 把过期的应收单标记为「已逾期」，并在账龄汇总里显示「逾期金额」。**催款动作要人工做**（打电话、发消息确认），系统不会自动发催款通知。

**Q：一单里既有现金又有挂账，是不是记两笔？**
A：是的。系统会记一笔现金收款（表示真的收到了这笔钱）和一张应收单（表示剩下的欠款）。这也叫「部分挂账」。

**Q：销账记录可以修改或删除吗？**
A：不可以。销账记录和会员流水一样，**只追加、不修改、不删除**。记错了只能再走一笔更正动作，并且写清备注。

**Q：为什么我销账时提示「销账金额超出未结金额，剩余 ¥40.00」？**
A：说明你填的金额大于还没还的部分。系统会把剩余金额告诉你，改成不超过这个数即可。

**Q：挂账主体必须关联顾客吗？**
A：不一定。类型选「公司」或「员工」时不需要关联顾客；类型选「顾客」时建议关联，这样系统能校验「这个挂账主体是不是这个顾客的」。
