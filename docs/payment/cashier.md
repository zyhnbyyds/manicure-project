# 收银台操作

## 这个模块解决什么问题

顾客做完项目到前台结账时，前台要在一分钟内回答清楚：**这单该收多少、已经收了多少、这次收多少、用什么方式收**。收银台把这三栏并排放在一屏里：左边是还没收完钱的单据队列，中间是这张单子的金额明细，右边是这次要用的收款方式。

它同时解决几个现实问题：

- 定金、尾款分两次收（预约时收定金，到店做完收尾款）；
- 一次结账用多种方式组合付款（余额 + 现金 + 挂账）；
- 顾客用自己的微信 / 支付宝扫店家的码，需要如实记账到人、到单；
- 次卡顾客不用付钱，但要核销一次次数；
- 微信 / 支付宝的线上扫码收款能自动确认到账，不用店员盯着手机看。

> 💡 大白话：收银台就是「一张单子收钱的收口」。所有钱的动作都从这里发起，收完之后「支付流水」里会留下一条记录，预约单上的「已收 / 尾款」由系统自动重算。

## 谁来用（适用角色）

| 角色          | 能做什么                                               |
| ------------- | ------------------------------------------------------ |
| 前台 / 收银员 | 选单、收款、录线下收款、核销次卡、关掉超时的线上支付单 |
| 店长          | 前台全部动作 + 退款审批 + 应收销账                     |

收银台上能操作什么，取决于账号有没有这些权限：

| 权限点（后台配角色时显示的项） | 管什么                                   |
| ------------------------------ | ---------------------------------------- |
| 收银台-创建收款                | 能看到并点击「去收款」；没有它按钮不显示 |
| 收银台-关闭支付单              | 能点「改现金收款」这类关单动作           |
| 退款审批-申请                  | 能发起退款申请（审批仍然只有店长有）     |
| 应收台账-销账                  | 能在收银台处理挂账补收                   |

## 操作路径

后台管理端 → 左侧菜单「美甲预约」→「收银台」，或直接访问 `/biz/cashier`

页面标题是「收银台」，副标题是「待收款队列 → 单据金额明细 → 混合支付；金额一律以服务端重算为准」。

## 分步操作

### 一、开台 / 选单（左栏 → 中栏）

1. 打开收银台，左栏「待收款队列」自动分三组：
   - **未收**（红色）：这笔预约还没收过一分钱；
   - **待收尾款**（橙色）：收过一部分（通常是定金），还有尾款没结清；
   - **挂账**（蓝色）：这单走的是赊账，钱还没收到，等着销账。
2. 需要找特定顾客时，在左栏搜索框输入**单号 / 姓名 / 手机号**，点「查询」。也可以点右上角「刷新队列」重新拉取（顾客刚付完款、别处刚下单时用得上）。
3. **单击**左栏里的某张单据，中栏会显示这张单子的完整信息：
   - 顾客姓名 / 手机号 / 美甲师 / 预约时间段；
   - 会员信息（等级、可用余额、积分）——账号没有会员查看权限时会显示「非会员 / 无会员查看权限」，**这不影响收款**；
   - 金额明细：项目原价、等级优惠、积分抵扣、手动改价、应付金额、已收金额、已收渠道、已退款、待收尾款；
   - 项目明细表：项目名、时长（分钟）、价格（元）。
4. 核对无误后进右栏收款。

### 二、收定金（预约下单时）

1. 定金是在**预约管理**下单时决定的：下单表单里选「定金」并填金额，系统会立刻把定金记为一张收款单。
2. 不填金额时，系统按门店配置的默认定金比例算（默认 **30%**）。例如项目原价 200 元，默认定金就是 60 元。
3. 定金收完，这单在收银台就落到「待收尾款」组，尾款 = 应付 − 定金。例如应付 200 元、定金 60 元，待收尾款 140 元。

> 💡 大白话：定金只是「先收一部分」，不是说这单打完折了。应收账款始终是全额，定金只影响「已收」和「待收尾款」两个数字。

### 三、收尾款（到店做完项目后）

1. 在左栏「待收尾款」组里点开单据。
2. 右栏会自动加一行现金，金额**预填为全部待收尾款**。看到提示「默认已填入全部待收尾款，如只收一部分请直接改小金额」时要注意：
   - 顾客一次付清 → 不用改，直接往下走；
   - 顾客这次只付一部分 → **手动把金额改小**。否则会一次性记成全额收款，事后要退款就得走审批流程。
3. 选好支付方式、核对「本次收款合计」和「差额」，点「去收款」。
4. 系统弹出「结算确认」窗，写明单据号、本次收款合计、几笔、是否含在线扫码、是否用了积分、是否含次卡核销。核对后点「确认收款」。
5. 收款成功后提示「收款成功，单据金额已重算」，队列和中栏金额会同时刷新。

### 四、混合支付（余额 + 现金 + 挂账叠加）

1. 右栏点「添加一行」，就能多加一种收款方式。每行选渠道、填金额。
2. 例如应收 200 元：第一行「储值余额」120 元，第二行「现金」80 元。系统会生成**两张支付单**，中栏「已收渠道」显示「balance,cash」这类组合。
3. 常见组合：
   - 余额 + 现金：余额不够的部分用现金补；
   - 现金 + 挂账：先收一部分现金，剩下的赊账；
   - 次卡核销 + 现金：一部分项目用次卡，超出的项目收现金。
4. 点「去收款」后，确认窗会告诉你一共几笔、合计多少、是否含在线扫码。
5. 系统校验规则（都是硬拦，改不了）：
   - 本次收款合计不能超过待收尾款，否则提示「本次收款合计 ¥X 超过应收尾款 ¥Y」；
   - 每一笔金额必须大于 0（次卡核销行没有金额，不用填）；
   - 挂账必须选挂账主体，否则提示「挂账必须选择挂账主体」；
   - 储值余额不足会直接报「储值余额不足：当前可用 ¥X，余额不足不会部分扣减」。

### 五、线下收款记账（现金 / 店家自己的收款码）

1. 右栏渠道选「现金」「微信线下收款码」或「支付宝线下收款码」。
2. 这三个方式是**只记账、不经系统渠道**的：点确认后就立即记成成功收款，不需要顾客做什么，也不需要等回调。
3. 现金行会多出一个「实收(元)」输入框：
   - 顾客给整数不找零 → 应收和实收填一样；
   - 顾客给多了要找零 → 应收填实际该收的钱，实收填顾客递过来的钱。例如应收 280 元、顾客给 300 元，实收填 300，系统按 280 入账。
   - **只有现金允许实收大于应收**，其它方式实收超过应收会被拒绝。
4. 顾客扫的是**店家自己的收款码**（贴在台面上的那张）时，就用「微信线下收款码 / 支付宝线下收款码」，看到顾客手机上的付款成功页再确认。

### 六、次卡核销

1. 右栏添加一行，渠道选「次卡核销」。
2. 该行金额框是灰的（次卡核销不产生金额），下方出现「选择要核销的次卡」下拉，列出该顾客**生效中**的卡，格式如「基础款 10 次卡（C20260101001，剩余 7 次）」。
3. 选好卡点「去收款」。系统会核销一次。
4. 三条硬规则：
   - 次卡核销**不产生金额、不叠加等级折扣**（这行不会算钱）；
   - 只能核销**卡种适用项目**里的项目，核销按预约的第一个项目判定；
   - 次卡核销**必须关联预约**（所以挂账补收那种独立收款不能核销次卡）。
5. 核错了怎么办：去「会员次卡」页找到这张卡，点「撤销核销」，填写撤销原因，次数会回补。

### 七、储值余额支付

1. 右栏添加一行，渠道选「储值余额」。
2. 该行下方会显示「可用余额 ¥X（本金 ¥Y / 赠送 ¥Z）；余额不足会直接失败，不做部分扣减」。
3. 余额充足就正常收款；余额不足会直接被拒绝，**不会自动扣到 0 再让你补现金**。这时请拆成两行：余额行填余额能覆盖的金额，剩下的用现金或其它方式。

### 八、在线扫码收款（微信 Native / 支付宝扫码）

1. 右栏添加一行，渠道选「微信 Native 扫码」或「支付宝扫码」，填金额。
2. 提交后弹出「扫码收款」窗，显示渠道名（微信 Native 扫码 / 支付宝扫码）和应收金额。
3. 窗口里显示二维码内容、**5 分钟倒计时**，并且**每 3 秒自动查询一次渠道支付状态**。顾客付款成功后会自动提示「支付成功，单据金额已刷新」，队列和中栏一起刷新。
4. 当前版本的注意事项（务必记住）：
   - 界面**没有内置二维码图片渲染**，二维码是以**文字内容 / 支付链接**的形式显示的。点「复制二维码内容」把内容复制出来，用能生成二维码的工具（或渠道自带的收款设备）让顾客扫。
   - 渠道给的其实是支付链接（微信是 `weixin://` 开头，支付宝是 `https://qr.alipay.com/` 开头），**不能当图片看**。
5. **5 分钟到期**后（界面显示「二维码已过期」），有两条出口：
   - 「**重新获取**」：先关掉这张超时的支付单，再按刚才完全相同的收款内容重新下一单、生成新二维码；
   - 「**改现金收款**」：关掉这张在线支付单，把本次收款改成现金，金额自动带你确认后重新提交。
6. **关闭弹窗不等于这笔没付。** 关闭前系统会主动向渠道查一次状态；如果顾客刚好在关窗前扫完码，状态会当场更新。

> 💡 大白话：二维码过期只是「这张待支付单作废了」，不是「钱收不到了」。顾客可能在你点关闭的同一秒付款成功——所以关闭弹窗前系统一定会再查一次渠道。

### 九、挂账（赊账）

1. 右栏添加一行，渠道选「挂账」，金额填本次赊账的钱。
2. 下方出现「挂账主体」下拉，选项形如「某美妆公司（公司，剩余额度 ¥4800.00）」「员工内部挂账（员工，额度不限）」。多笔挂账共用同一个主体。
3. 挂账可以和别的渠道叠加，例如余额 20 元 + 挂账 180 元。
4. 提交后预约的「资金状态」变成**挂账**，同时在「应收台账」里生成一张应收单，等主体来结账时销账。
5. 挂账**不产生积分**（积分跟着钱走，钱还没收到）；等销账、钱真正到账时才累计。

### 十、积分抵扣（在收银台）

1. 右栏「积分抵扣」区域，先点「**试算上限**」。
2. 系统提示「最多可用 X 分，可抵 ¥Y」，说明写得很直白：「100 分抵 1 元、单笔上限 30%，服务端复算为准」。
3. 把想用的积分数填进「使用积分数」框（可以填得比上限小，也可以直接填上限值）。
4. 只有**整笔抵扣**：想用积分抵扣金额 X 元，就必须有 X×100 分；积分不够会直接失败，不会「抵扣到 0 就算了」。
5. 积分抵扣可以和等级折扣叠加，中栏「积分抵扣」那一行会显示实际抵掉多少钱。

### 十一、收款后打印与小票口径

1. **系统当前没有小票打印功能**：收银台和支付流水页面上没有打印按钮，系统也不会生成纸质凭证模板。请不要向顾客承诺「系统可以打小票」。
2. 正确的收款凭证口径是**电子记录**：
   - 顾客要看付款凭证 → 用顾客自己微信 / 支付宝里的付款记录，或收银台弹窗显示的渠道交易信息；
   - 门店要对账 / 查单 → 到「支付流水」页按支付单号、预约号、时间、渠道筛出那一笔，点「详情」看「渠道交易号」「支付时间」「回调时间」，以及「渠道轨迹」里的每一次动作（创建支付单 / 渠道回调 / 主动查单 / 关单 / 退款 / 回调验签失败）。
3. 需要纸质收据的门店，请自行准备手写收据本；系统里的金额仍然必须如实录入，**不要因为「打了张纸」就不在系统里记账**。
4. 收款成功时系统会自动给顾客发一次到店 / 充值类通知（通知模板由店长维护），这是最接近「电子小票」的东西；通知模板的短信通道没配时只发站内消息。

## 使用注意事项

> ⚠️ **「待收尾款」的默认全额预填是个坑。** 打开一张待收尾款的单子时，系统会自动把全部尾款填进金额框，并弹提示「默认已填入全部待收尾款，如只收一部分请直接改小金额」。顾客只付一部分时**必须先改小金额**再提交，否则系统按全额入账，事后要退回多收的钱就得走退款审批。

> ⚠️ **不要连点「去收款」。** 点一次就已经落单了；按钮在提交期间会自动禁用，但网络慢时请耐心等提示，别反复点。混合支付一次提交会逐笔生成支付单，重复提交就会重复收款。

> ⚠️ **线上扫码收款的二维码 5 分钟就失效。** 到期后别让顾客再扫旧码（会失败），用「重新获取」出新码，或直接用「改现金收款」。**同一张单重新收款必须新建支付单**，所以「重新获取」会先关掉旧单——这是正常的，不是重复扣钱。

> ⚠️ **关掉扫码弹窗之前一定先确认状态。** 系统会在关闭前主动查一次渠道，但如果查不到（网络问题），请到「支付流水」里手动点「查单」确认。**在确认这笔线上支付失败 / 关闭之前，不要改收现金**，否则会出现「微信也收了、现金也收了」的双收，只能走退款。

> ⚠️ **次卡核销不会算钱，也不会打折。** 用了次卡的那部分不填写金额；如果顾客的项目超出次卡适用项目，超出的部分要单独加一行收款，不要指望系统自动拆分。

> ⚠️ **储值余额不足不会部分扣减。** 系统要么全额从余额扣，要么整笔失败。看到「余额不足不会部分扣减」这句提示时，请把金额拆成「余额 + 其它方式」两行。

> ⚠️ **小程序内支付尚未开通。** 顾客在小程序里点「微信支付」会看到「这个功能马上就来啦～」，余额 / 次卡 / 积分在小程序里也都标着「暂未开放」。**顾客只能到店用收银台的扫码 / 现金 / 线下收款码付钱。**

> ⚠️ **小程序里显示「已付清」才算真的付清。** 小程序在支付后是向服务端确认的（会轮询几次），确认不到会显示「等待支付结果」而不是「支付成功」。如果顾客说小程序上显示成功但收银台还是未收，**以收银台 / 支付流水为准**，先查单再决定是否改收现金。

> ⚠️ **挂账单在收银台也能补收。** 挂账的单据在收银台中间栏会提示「此处仍可用混合支付补收（挂账可与 balance 等渠道叠加）」。正式销账要去「应收台账」，在收银台收的是「先收一部分」，两者不要重复做。

## 常见问题

**Q：顾客结账时说要开发票 / 要小票，能打吗？**
A：系统目前不能打印小票或发票。收款凭证以「支付流水」里的记录为准（支付单号、渠道交易号、时间、金额）。需要纸质凭证请门店自备。

**Q：我点「去收款」后弹窗关掉了，但没看到二维码，是没成功吗？**
A：先看队列里的提示。只有选了「微信 Native 扫码 / 支付宝扫码」才会有二维码弹窗，而且系统会挑出**还需要顾客扫码的那一笔**弹窗。如果这次收款全是现金 / 余额 / 挂账 / 次卡，收款当场就成功了，不弹二维码。

**Q：扫码收款弹窗里显示的不是二维码图片，是一串字符。**
A：这是当前版本的已知限制（界面没有内置二维码渲染）。点「复制二维码内容」，把它转成二维码给顾客扫，或改用现金 / 线下收款码收款。

**Q：顾客扫了码，微信那边显示付款成功，但收银台还是「待支付」。**
A：先在弹窗里等几秒（每 3 秒自动查一次）。如果一直不变，到「支付流水」找到这笔单点「查单」。渠道到账通知偶尔会延迟，后台还有每 2 分钟一次的自动查单兜底。**确认之前不要重复收款。**

**Q：一张单子能做两次退款吗？**
A：可以，但只能退到「已收金额」为止。一张支付单退过一部分后状态会变成「部分退款」，剩余可退金额会相应减少，退不了超过实收的钱。

**Q：会员的储值本金和赠送余额有什么区别，扣哪个？**
A：可用余额 = 本金 + 赠送。系统按门店配置的扣减顺序扣，默认是**赠送优先**（这样顾客手上的可退本金留得更多）。赠送部分是送的，**不可退、不可提现**，退款只退本金。

**Q：收银台上看不到「会员」信息怎么办？**
A：那说明账号没有会员查看权限，界面会显示「非会员 / 无会员查看权限」。这**不影响收银**，但这样就没法用余额、次卡、积分了。需要这些功能请让店长在「角色管理」里加权限。
