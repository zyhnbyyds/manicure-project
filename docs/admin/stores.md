# 门店与连锁

> 💡 **只有一家店的话，这一页只需要看「A. 新建第一家门店」**。开第二家店、或者要让「A 店的人只看 A 店的数据」时，再回来看 C 和 D。

## 这个模块解决什么问题

- 把「门店」当成一条**档案**建起来（名称、地址、电话、营业时间、图片、地图坐标）——小程序的门店页和「导航到店」用的就是它。
- 决定**谁能看哪家店的数据**：预约、收款、退款、应收、报表、排班、首页都按这个范围隔离。
- 说清切门店之后**哪些数字会变、哪些不会变**——这是最容易误会的地方，见注意事项第 2 条。

## 谁来用（适用角色）

| 角色        | 能做什么                                                                                     |
| ----------- | -------------------------------------------------------------------------------------------- |
| 老板 / 超管 | 新建与编辑门店、设默认门店、给账号分配可见门店；**看得到全部门店**，并可随时切换             |
| 店长        | 只看得到分配给自己的门店（**一个条件都不传也只统计本店**）；不能改门店档案（门店是总部配置） |
| 前台        | 同上；且首页是**轻量版**（有单量与待办，不含任何金额）                                       |
| 美甲师      | 后台只读；日常在小程序「工作台」                                                             |

> 门店管理页面需要「门店管理」权限；「看全部门店并可切换」是另一个更高的授权（`system:store:all`），默认只给超管。

## 操作路径

| 想做的事           | 去哪                                                    |
| ------------------ | ------------------------------------------------------- |
| 建 / 改门店档案    | 系统管理 →「门店管理」（`/system/stores`）              |
| 让账号只看到某些店 | 系统管理 →「用户管理」→ 该账号行末的「设置可见门店」    |
| 切换当前门店       | 顶栏右侧的**门店切换器**（可见门店多于 1 家时才会出现） |

## 分步操作

### A. 新建第一家门店（单店也要做这一步）

1. 系统管理 →「门店管理」→ 右上角「新增门店」。
2. **必填两项**：
   - 「门店名称」：如「南京西路店」——小程序首页顶部、通知短信里都会用到它；
   - 「门店编码」：如 `MAIN` / `XJH`，**全系统唯一**，对账和报表里用来区分是哪家店。
3. **选填**（都能后补）：
   - 「英文副标题」：如 `BEAUTY NAILS`，显示在小程序首页门店名下方；不填就不显示这一行；
   - 「门店电话」「营业时间」（如 `10:00 - 20:00`，纯展示文案）、「门店地址」；
   - 「纬度 / 经度」：填了小程序才能「导航到店」；可以先留空；
   - 「公告」：小程序门店页展示的到店须知；
   - 「门店图片」：最多 5 张，**第一张当封面**；小程序首页头图轮播也优先用这里的图；
   - 「排序」：数字越小越靠前；「启用」开关控制这家店是否可用。
4. 保存。
5. **第一条门店会自动成为「默认门店」**：它是「没有指定门店时」的兜底（小程序门店页、单据落店都用它）。

### B. 设默认门店 / 删除门店

- **设为默认**：在列表里点那一行的**星标**。同一时刻只有一家默认，切了会自动取消原来那家。
- **删除**：删除是**软删**（数据保留，只是不再出现在列表里）。
  - ⚠️ **默认门店不能删**：先把默认切到别家，再删。
  - 删掉的门店，它的单据还在，但按店统计时不会再出现。

### C. 让某个账号只看到某几家店（多店的关键一步）

1. 系统管理 →「用户管理」，找到那个人的账号。
2. 点行末的「**设置可见门店**」，勾选他应该看到的门店，保存。
3. 语义是「**最终就是这几家**」（整体替换，不是追加）：
   - 勾 1 家 = 只能看这 1 家；
   - 勾多家 = 这几家的数据合起来看；
   - **一个都不勾 = 他看不到任何业务数据**（接口会明确报「未分配门店」，不是静默返回空）。
4. 保存后**立即生效**，不需要他重新登录。
5. 「用户管理」列表里那一列会显示他绑定的门店；**红色「未分配」就是这个账号什么都看不到**——这是「员工登录后一片空白」最常见的原因。

### D. 切换当前门店（顶栏切换器）

1. 顶栏右侧点门店名 → 选一家店（也可以选「全部门店」）。**只负责一家店的账号看不到这个切换器**，因为你的数据本来就只限本店。
2. 切换后，当前页面的列表、报表、首页**立刻按新门店重算**——不用刷新、不用重新登录。
3. 这个选择只保存在**你自己的浏览器**里，不影响同事；下次打开还是同一家店。

## 字段说明

| 字段        | 必填 | 说明                               | 备注                                                 |
| ----------- | ---- | ---------------------------------- | ---------------------------------------------------- |
| 门店名称    | 是   | 如「南京西路店」                   | 小程序首页顶部、通知模板里的 `{shopName}` 附近会用到 |
| 门店编码    | 是   | 如 `MAIN` / `XJH`，全系统唯一      | 重复会报「门店编码已被占用」                         |
| 英文副标题  | 否   | 如 `BEAUTY NAILS`                  | 小程序首页显示在中文名下方；不填就不显示             |
| 门店电话    | 否   | 顾客可拨打的号码                   | 小程序门店页展示                                     |
| 营业时间    | 否   | **纯展示文案**，如 `10:00 - 20:00` | 真正决定「能约几点」的是「排班管理」，不是这里       |
| 门店地址    | 否   | 文字地址                           | 小程序门店页展示                                     |
| 纬度 / 经度 | 否   | 小数点后 6 位                      | 填了小程序才能「导航到店」                           |
| 公告        | 否   | 到店须知，如「本周三店休」         | 小程序门店页展示                                     |
| 门店图片    | 否   | 最多 5 张，第一张当封面            | 小程序首页头图轮播优先用这里的图（最多取 3 张）      |
| 排序        | 否   | 数字越小越靠前                     | 影响切换器与门店列表的顺序                           |
| 启用        | 否   | 关掉 = 这家店不可用                | 关闭后它不再出现在切换器与小程序门店列表里           |
| 默认门店    | —    | 列表里点星标设置，**同城最多一家** | 默认门店不可删除                                     |

## 使用注意事项

> ⚠️ **「可见门店」和角色的「数据范围」是两套东西，别混用。**
> 触发条件：想让「A 店的人只看 A 店数据」。
> 后果：去「角色管理」调「数据范围」是**没用的**——数据范围只管后台基座那几张表（用户、部门、登录日志、操作日志）。
> 正确做法：去「**用户管理 → 设置可见门店**」。预约、收款、退款、应收、报表、排班、首页都按它隔离。

> ⚠️ **会员资产是全店通兑的一个池子，所以有些数字切门店也不会变。**
> 触发条件：切到 A 店后对比「期末结存 / 新增会员 / 次卡发售」。
> 后果：以为切换器坏了。
> 正确做法：记住分界线——**「在哪家店发生的」按店，「这家公司现在有多少」全店**。
> 按店变的是：净营收、退款、单量、客单价、储值充值/赠送、积分发放/抵扣、次卡核销；
> **恒为全店**的是：期末结存、新增会员、次卡发售（页面上会标「全店」）。

> ⚠️ **没有门店归属的历史流水，不会算进任何一家店。**
> 触发条件：按门店看报表时，合计比「全部门店」少一点。
> 后果：以为丢数据了。
> 正确做法：这是刻意的「宁少不多」——把别店的钱算进来比少算更难发现。要核对总量请看「全部门店」。

> ⚠️ **美甲师能服务哪几家店，是单独配的。**
> 触发条件：某位美甲师在 B 店排不了班 / 选不到。
> 正确做法：在「美甲师」详情里配置他的**可服务门店**；**不配 = 全部门店都行**，只配了 A 店就只在 A 店可选。

> ⚠️ **当前是「连锁直营、统一结算」：钱进同一个账户，不支持按门店配商户号。**
> 触发条件：想让每家店用自己的收款码、自己跟平台结算。
> 正确做法：这属于「加盟/独立结算」，当前版本不做，需要另行改造。

## 常见问题

**Q：员工登录后左边菜单是空的、首页提示「未分配门店」？**
A：他还没被分配可见门店。系统管理 →「用户管理」→「设置可见门店」勾上他该看的门店，保存后立刻生效。

**Q：为什么店长看得到别家店的单？**
A：两种可能：① 他的可见门店里勾了别家店；② 他拥有「看全部门店」的特权（超管）。去「用户管理」核对那一列的门店。

**Q：切到 A 店后，为什么「期末结存 / 新增会员」没变？**
A：这三项是**全店口径**（余额、积分、次卡是全店通兑的一个池子），页面上标了「全店」。按店变的只有「发生额」类指标。

**Q：门店图片传了 5 张，小程序首页轮播用的是哪几张？**
A：优先用门店图片，最多取 3 张（按上传顺序）；一家的门店图片不足 2 张时，会用「人气款式」的封面补上；一张都没有时才用内置图片。

**Q：门店营业到凌晨，营业日怎么算？**
A：目前按**店内自然日** 00:00–24:00 切分，没有「凌晨算前一天」的开关。凌晨 00:30 收的钱算当天。需要按营业日结账的门店，请把收款时间对齐到自然日内。

**Q：门店停用了会怎样？**
A：它不再出现在门店切换器和小程序门店列表里；绑着它的账号如果**再无其它可见门店**，访问业务数据会被明确拒绝（提示未分配门店），而不是静默显示空列表。

**Q：默认门店能改吗？能删吗？**
A：能改（列表点星标）；**不能删**——删了就没有「没指定门店时」的兜底了。要先建好并切换默认门店，再删旧的。
