# 后台管理端总览

> 💡 后台管理端就是你在电脑浏览器里打开的那个「美甲管理系统」网页。顾客用小程序，员工用这个后台。

## 这个模块解决什么问题

- 告诉你后台长什么样：菜单在哪、按钮在哪、找不到某个功能时去哪儿找。
- 教你三件每天都在做的事：**登录**、**改自己的资料和密码**、**退出登录**。
- 把「为什么我看不到某个菜单/按钮」这类问题一次说清。

## 谁来用（适用角色）

- 全部后台账号：店长、老板、前台、收银、运营。
- **能看见什么，取决于你账号被分配的角色**。同一个页面，不同人的按钮数量可能不一样，这是正常的。

## 操作路径

后台管理端的入口地址由你的技术同事或服务商提供（一般是形如 `http://门店服务器地址/` 的网址）。

登录后默认进入「首页」，地址是 `/dashboard`。

## 分步操作

### A. 登录

1. 打开后台网址，进入登录页。
2. 输入「用户名」和「密码」，点「登录」。
3. 成功后右上角提示「登录成功」，进入首页。
4. 登录失败时页面会给出提示（用户名或密码不正确、账号被禁用等），按提示处理。

> ⚠️ 登录页右侧还有一个「立即注册」入口。**不要让员工用它建号**，原因见注意事项。

### B. 认识界面

登录后屏幕分成四块：

| 区域       | 位置           | 里面有什么                                                                                                       |
| ---------- | -------------- | ---------------------------------------------------------------------------------------------------------------- |
| 侧边栏     | 最左边         | 顶部是店招「美甲管理系统」，中间是菜单树，最下方一个箭头按钮可以**收起/展开**侧边栏                              |
| 顶部工具栏 | 最上方         | 左边显示当前页面的名字；右边依次是：暗色模式切换、主题设置、**AI 助手**、GitHub 链接、你的头像（点开是用户菜单） |
| 页签栏     | 顶部工具栏下方 | 你打开过的页面会变成一个一个页签，可以快速来回切                                                                 |
| 内容区     | 中间大片区域   | 当前页面的内容                                                                                                   |

菜单结构：

```
首页
系统管理 ── 用户管理 / 角色管理 / 菜单管理 / 部门管理 / 岗位管理 / 字典管理 / 参数配置
系统监控 ── 登录日志 / 操作日志 / 在线用户 / 缓存监控
定时任务
文件管理
代码生成器
美甲预约 ── 25 个业务页面（服务项目、美甲师、排班管理、顾客档案、预约管理、
           收银台、会员、次卡、挂账、报表、提成、通知…）
```

> 💡 「AI 操作」不在左侧菜单里，它由**顶部工具栏的机器人图标**唤出（见 [AI 操作助手](./ai-assistant.md)）。

### C. 用页签栏快速切页

1. 打开一个新页面，页签栏会自动多一个标签。
2. 点标签切换页面；点标签上的 `×` 关闭它。
3. 在标签上**点右键**，可以选择：
   - 「关闭当前」
   - 「关闭其他」——只留当前这一个
   - 「关闭所有」——回到只剩首页
4. 「首页」这个标签**不能关闭**，它永远在。

### D. 改自己的资料

1. 点右上角你的头像 → 选「个人中心」（也可以直接访问 `/profile`）。
2. 左侧「个人资料」卡片里：
   - 点「更换头像」选一张图片（**小于 2MB**，非图片会提示「请选择图片文件」）。上传成功后提示「头像已上传，保存资料后生效」。
   - 确认「显示名称」（必填）、「邮箱」（选填，格式错会提示）、「手机号」（选填）。
   - 点「保存资料」，提示「资料已更新」后立即生效。
3. 想删头像，点「移除」，再「保存资料」。

### E. 改密码

1. 在「个人中心」右侧「修改密码」卡片。
2. 填「原密码」、「新密码」（**最少 8 个字符**）、「确认密码」。
3. 两次新密码不一致会提示「两次输入的新密码不一致」。
4. 点「修改密码」，提示「密码修改成功」。
5. 原密码填错会提示「原密码不正确」。

> ⚠️ 改完密码**不会**把其它设备上的登录踢下线（见注意事项）。

### F. 退出登录

1. 点右上角头像 → 选「退出登录」。
2. 提示「已退出登录」并回到登录页。

### G. 换主题 / 换暗色

- 点顶部工具栏的月亮/太阳图标，在「浅色 / 深色」之间切换。
- 点调色板图标打开主题面板，可以改主色等外观。**这只影响你自己的电脑**，不影响同事。

## 字段说明

### 顶部工具栏

| 图标          | 功能         | 说明                                                                                      |
| ------------- | ------------ | ----------------------------------------------------------------------------------------- |
| 月亮 / 太阳   | 切换暗色模式 | 只影响当前浏览器                                                                          |
| 调色板        | 主题设置     | 改主色、界面风格                                                                          |
| 机器人        | **AI 助手**  | 需要 `ai:chat` 权限，点开从底部滑出 AI 面板；按 `Esc` 或右上角 `×` 关闭；换页面会自动关闭 |
| GitHub        | 项目仓库链接 | 给技术同事用的，普通门店人员可以忽略                                                      |
| 头像 + 用户名 | 用户菜单     | 「个人中心」「退出登录」                                                                  |

### 个人中心表单

| 字段     | 必填 | 说明               | 填错会怎样                                                              |
| -------- | ---- | ------------------ | ----------------------------------------------------------------------- |
| 显示名称 | 是   | 后台里显示的名字   | 留空无法保存                                                            |
| 邮箱     | 否   | 选填               | 格式不对会提示「邮箱格式不正确」                                        |
| 手机号   | 否   | 选填               | —                                                                       |
| 头像     | 否   | 图片，单张最大 2MB | 超过 2MB 提示「头像图片不能超过 2MB」；选了非图片提示「请选择图片文件」 |
| 原密码   | 是   | 当前使用的密码     | 不对会提示「原密码不正确」                                              |
| 新密码   | 是   | 至少 8 个字符      | 少于 8 位无法提交                                                       |
| 确认密码 | 是   | 再输一遍新密码     | 不一致会提示                                                            |

## 使用注意事项

> ⚠️ **登录页的「立即注册」是开放的，别让员工自己注册。**
> 触发条件：任何能打开后台网址的人点「立即注册」都能建一个账号（注册后会自动登录）。
> 后果：自助注册的账号只被分配「普通用户」角色，**看不到任何业务菜单**（只能看到首页和个人中心）；同时这意味着后台网址不适合暴露在公网，也容易被建出无用账号。
> 正确做法：员工账号一律由店长在「用户管理」里新建并分配角色；同时请技术同事评估是否关闭注册入口，并不要把后台网址放到公网。

> ⚠️ **改了密码不会把其它设备踢下线。**
> 触发条件：怀疑账号被人用了，改完密码就以为安全了。
> 后果：原来的登录状态（在别的电脑/手机上）仍然能用，直到它自己的登录有效期到期。
> 正确做法：改完密码后，去「系统监控 → 在线用户」把可疑的会话点「下线」。详见 [系统监控](./monitor.md)。

> ⚠️ **菜单和按钮是「按角色给」的，看不见不等于坏了。**
> 触发条件：同事能点「新增用户」，你只看到列表。
> 后果：容易以为系统出故障，反复刷新。
> 正确做法：先确认自己的角色权限（需要的话找店长在「角色管理」里勾选），再看 [用户与角色](./users-roles.md)。

> ⚠️ **权限改动要重新登录（或等最多 15 分钟）才生效。**
> 触发条件：刚给某人加了菜单权限，他那边还是看不到。
> 后果：以为没保存成功。
> 正确做法：让他退出重新登录一次；不着急的话等一会儿也会自动生效。

> ⚠️ **不要多人共用同一个账号。**
> 触发条件：前台几个人用同一个用户名。
> 后果：「操作日志」里分不清是谁改的，出了问题没法追责；在线用户也只能看到一条记录。
> 正确做法：一人一号，岗位变动就停用旧账号。

> ⚠️ **换页签不等于退出。**
> 触发条件：离开工位只关掉了页签。
> 后果：账号仍在登录状态，别人可以直接操作。
> 正确做法：离店或换人时点「退出登录」。

## 常见问题

**Q：忘记密码了怎么办？**
A：找店长或有「用户管理」权限的同事，在「用户管理」里编辑你的账号，填一个新密码（**最少 12 位**）保存，然后用新密码登录。系统没有「忘记密码自助重置」功能。

**Q：为什么我的首页和别人不一样？**
A：「首页」上的卡片是按权限显示的：有用户管理权限才显示「用户总数」，有缓存权限才显示「缓存键数」，没有登录日志权限就看不到下面的图表。这是正常现象。

**Q：首页为什么不显示营业额？**
A：首页是**系统运行概览**（用户数、部门数、登录趋势等），不含经营数字。看营业额请去「报表中心」，见 [报表与经营分析总览](../report/index.md)。

**Q：为什么点菜单提示「没有操作权限」或跳 403 页面？**
A：你的角色没有被勾选这个菜单，或者这个页面的按钮权限点没给。请联系店长在「角色管理」里调整。

**Q：页签太多太乱怎么办？**
A：在任意页签上点右键，选「关闭其他」；或者点最右侧的箭头把侧边栏收起来，给内容区腾地方。

**Q：可以用手机浏览器打开后台吗？**
A：技术上可以打开，但后台是给电脑大屏设计的（表格很宽），建议用电脑操作；顾客侧请使用小程序。

**Q：AI 助手图标点了没反应 / 说未配置？**
A：AI 助手默认是关闭的（会走演示模式），需要技术同事配置后才好用。详见 [AI 操作助手](./ai-assistant.md)。

**Q：我改了暗色主题，会影响别人吗？**
A：不会。主题、暗色、侧边栏收起状态都只保存在你自己的浏览器里。
