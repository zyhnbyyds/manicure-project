## 这份手册是什么

写给**门店使用者**（店长、前台、美甲师）的操作说明：每个模块**怎么点、填什么、注意什么坑**。

不解释技术实现，也不需要你懂任何开发知识。手册里的每一句话都对应系统里真实存在、可以点到看到的行为。

## 系统由三个客户端组成

| 客户端               | 谁用                         | 打开方式                                     | 主要干什么                                           |
| -------------------- | ---------------------------- | -------------------------------------------- | ---------------------------------------------------- |
| **后台管理端**       | 店长、前台（有账号的店员）   | 电脑浏览器                                   | 建档、排班、开单收款、会员与卡、报表提成、系统设置   |
| **微信小程序顾客端** | 顾客                         | 微信里的小程序                               | 看项目与美甲师、自助预约与取消、看余额积分次卡与通知 |
| **美甲师工作台**     | 美甲师（在小程序里切换模式） | 微信小程序（同一份小程序内的「工作台模式」） | 今日班次与今日单、到店/完成打卡、我的业绩与评价      |

> 💡 **什么是「工作台模式」**：小程序里有两套底部菜单。顾客模式是「首页 / 预约 / 我的」，工作台模式是「工作台 / 我的预约 / 我的」。美甲师用自己的手机号申请开通后，在「我的」里切换过去；能不能进，由店长在后台「工作台授权」里说了算。

## 五分钟上手路线

1. 先读 [总览](./guide/index.md)，理解「后台建档 → 小程序顾客预约 → 到店打卡 → 收银结算」这条主线；
2. 照着 [快速上手](./guide/quickstart.md) 按顺序配置 7 件事，配完就能开门做生意；
3. 用 [角色与权限](./guide/roles.md) 给店员分账号，**先分配好权限再让他们上手**；
4. 每天照着快速上手里的「开店 / 闭店清单」走一遍；
5. 出问题先查 [常见问题总汇](./guide/faq.md)，再去看对应模块页的「使用注意事项」。

::: warning 三条最容易出事的地方

1. **顾客到店后一定要及时点「到店」**：预约会在一段容忍期后被系统自动记为「爽约」；
2. **排班改动会撞到已有预约**：系统会先弹出受影响清单拦住你，别急着点「强制保存」；
3. **退款不会自动发生**：取消或爽约后，钱要另外到「退款审批」发起申请，店长审批通过才会退。
   :::
